Getting Started

Reference playbook for EDS + DA — implementation-first, use-case-led, lightweight.

What this is

A curated collection of real-world implementation patterns for EDS and DA, grounded in the working scdemos/demo codebase. It bridges official Getting Started tutorials and the enterprise use cases teams actually ship.

Included What you get

Reference-first
The implementation is the artifact — not the prose around it.
Use-case-led
Chapters frame business problems, not block APIs.
Lightweight
No framework, no build step, no governance overhead.
Inspectable
Every snippet links to a specific file in scdemos/demo.

Out of scope What we skip

Not a starter kit
Not another boilerplate, framework, or clone of aem-boilerplate.
Not blessed architecture
Assume gray-area patterns — useful reference, not official Adobe doctrine.
Not a doc portal
We link to aem.live and docs.da.live instead of duplicating them.
