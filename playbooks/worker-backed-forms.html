Worker-backed forms

A JSON form definition fetched at decoration time, a Cloudflare Worker that proxies the submission, and a downstream system (Slack, n8n, CRM) that holds the secrets. Authors get a no-code form, devs keep secrets out of the browser.

Forms Workers Slack Secrets

Problem

Marketing wants a contact form on the site. The form data needs to land in Slack (or n8n, or a CRM, or a Salesforce lead). The Slack webhook is a secret — you can't paste it into the page source. You also don't want to ship a different block per integration.

Two interchangeable form blocks ship in the demo: blocks/form/form.js (full JSON-driven builder) and blocks/n8n-form/n8n-form.js (table-driven, simpler). Both follow the same architecture — the only differences are the schema and where the submit URL points.

Code snippets

1. Form block — fetches JSON definition

Authors point the block at a JSON file in the same content tree (or a published spreadsheet). The block fetches it during decoration, builds the DOM, and applies HTML5 validation.

blocks/form/form.js (excerpt) View on GitHub → 
async function handleSubmit(form) {
  const status = form.querySelector('.form-status');
  try {
    const payload = generatePayload(form);
    const body = { data: payload };       // wrap for the worker
    toggleForm(form);                     // disable inputs
    setStatus('Sending...');

    const response = await fetch(form.dataset.action, {
      method: 'POST',
      body: JSON.stringify(body),
      headers: { 'Content-Type': 'application/json' },
    });

    if (!response.ok) throw new Error(await response.text());
    if (form.dataset.confirmation) {
      await replaceWithThankYou(form, form.dataset.confirmation);
    } else {
      setStatus('Thanks! Your message has been sent.');
      form.reset();
    }
  } catch (e) {
    setStatus('Unable to submit right now. Please try again.');
  } finally {
    toggleForm(form, false);
  }
}

The submit URL (form.dataset.action) comes from the JSON definition's submit field — either an absolute URL to a worker, or a same-origin path that hits the worker through the CDN.

2. Cloudflare Worker — proxy with secrets

workers/contact_us/index.js View on GitHub → 
const corsHeaders = {
  'Access-Control-Allow-Origin': '*',
  'Access-Control-Allow-Methods': 'POST, OPTIONS',
  'Access-Control-Allow-Headers': 'Content-Type',
};

export default {
  async fetch(request, env) {
    if (request.method === 'OPTIONS') {
      return new Response(null, { status: 204, headers: corsHeaders });
    }
    if (request.method !== 'POST') {
      return new Response('Method not allowed', { status: 405, headers: corsHeaders });
    }
    if (!env.SLACK_WEBHOOK_URL) {
      return new Response('Worker not configured', { status: 500, headers: corsHeaders });
    }

    let body;
    try { body = await request.json(); }
    catch { return new Response('Invalid JSON body', { status: 400, headers: corsHeaders }); }

    // Accept { data: { name, message } } (form block) or { name, message } (flat)
    const payload = body?.data || body || {};
    const { name, message } = payload;
    if (!name || !message) return new Response('Missing fields', { status: 400, headers: corsHeaders });

    const slackPayload = { text: `📩 New Contact Form Submission\n*Name:* ${name}\n*Message:* ${message}` };
    const webhookResponse = await fetch(env.SLACK_WEBHOOK_URL, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(slackPayload),
    });
    return new Response('OK', { status: webhookResponse.ok ? 200 : 500, headers: corsHeaders });
  },
};

The Slack webhook URL is a Cloudflare Workers secret — set with npx wrangler secret put SLACK_WEBHOOK_URL and never exposed to the page.

3. Variant — n8n-form for simpler table-driven authoring

For lighter use cases, the n8n-form block reads its config straight from the block table (no JSON file). It POSTs application/x-www-form-urlencoded to any URL — typically an n8n Form Trigger:

blocks/n8n-form/n8n-form.js (excerpt) View on GitHub → 
const headers = { 'Content-Type': 'application/x-www-form-urlencoded' };
if (bearerToken && bearerToken.trim()) {
  headers.Authorization = `Bearer ${bearerToken.trim()}`;
}
const response = await fetch(submitUrl, { method: 'POST', body: formData, headers });

The Bearer token can be set via data-bearer-token on the block or window.n8nFormBearerToken. For an authenticated workflow, fetch a short-lived token from a worker in scripts/delayed.js and assign it before the form decorates.

Notes & gotchas

  • Don't put secrets in the page. The whole point of the worker is to keep credentials out of main.html. If you find yourself thinking "I'll just write the webhook URL in a config block" — stop, route through a worker.
  • Body shape matters. The form block sends { data: payload }. The worker accepts both { data: ... } and a flat object so you can swap clients without changing the worker.
  • CORS preflight. Browsers send OPTIONS first when the body is JSON or when a custom header is present. Always handle OPTIONS with 204 + CORS headers — the demo worker shows the canonical pattern.
  • Validation lives in two places. Client-side HTML5 validation is for UX (form.reportValidity()); the worker re-validates required fields server-side because the client check is bypassable.
  • Spam & abuse. A public worker endpoint is a goldmine for bots. Add Cloudflare Turnstile: render the widget inside the form, attach the token to the payload, and verify in the worker before forwarding.
  • Rate limiting & observability. Add a Workers KV / Durable Object counter for per-IP throttling, and use console.log + Workers Analytics for traffic baselines.

How to adapt into my project

  1. Pick the form variant. If authors author a JSON file, use blocks/form. If they prefer a block table with 3-4 fields, use blocks/n8n-form.
  2. Copy workers/contact_us as your starting point. Replace the Slack-specific payload-building with whatever your downstream API expects (n8n, Salesforce, HubSpot, custom webhook, queue producer).
  3. Set worker secrets: npx wrangler secret put SLACK_WEBHOOK_URL (and any others). Never bake them into wrangler.jsonc or env vars in code.
  4. Route from the page. Either set submit in the form JSON to https://your-worker.<account>.workers.dev, or front the worker behind a CDN route so it shares your origin and CORS becomes trivial.
  5. Add Turnstile + rate limiting. Skip this only if traffic is internal-network or behind Access. For public pages, treat it as required.
