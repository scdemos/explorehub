# Fonts (helix-website parity)

Copy Adobe Clean and Source Code Pro WOFF2 files from `helix-website/fonts/` into this folder:

- `adobe-clean-400.woff2`
- `adobe-clean-400-italic.woff2`
- `adobe-clean-700.woff2`
- `adobe-clean-900.woff2`
- `source-code-pro-400.otf.woff2`
- `source-code-pro-400-italic.otf.woff2`
- `source-code-pro-700.otf.woff2`

Until those files are present, the site uses **Trebuchet MS** (local) and **Source Code Pro** (Google Fonts fallback) per `styles/fonts.css`.
