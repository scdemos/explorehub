How to Build a Columns Block

Create responsive multi-column layouts with automatic column counting and image detection

Block Layout Responsive Beginner

Overview

The Columns block enables authors to create multi-column layouts without writing CSS. It automatically detects the number of columns, identifies image-only columns for special styling, and provides responsive behavior that stacks columns on mobile devices.

Key Features:
  • Automatic Column Counting: Adds columns-N-cols class based on column count
  • Image Column Detection: Identifies and styles image-only columns differently
  • Responsive: Multi-column on desktop, stacked on mobile
  • Flexible Content: Supports text, images, headings, lists, and nested blocks

Step 3: JavaScript Decoration

The blocks/columns/columns.js file analyzes the structure and adds semantic classes:

export default function decorate(block) {
  // Count columns from first row
  const cols = [...block.firstElementChild.children];
  block.classList.add(`columns-${cols.length}-cols`);  // ← Adds count class

  // Detect image-only columns
  [...block.children].forEach((row) => {
    [...row.children].forEach((col) => {
      const pic = col.querySelector('picture');
      if (pic) {
        const picWrapper = pic.closest('div');
        if (picWrapper && picWrapper.children.length === 1) {
          // Only a picture, no other content
          picWrapper.classList.add('columns-img-col');  // ← Marks image columns
        }
      }
    });
  });
}

Step 5: CSS Styling

Finally, blocks/columns/columns.css creates responsive column layouts:

/* Mobile: stacked by default */
.columns > div {
  display: flex;
  flex-direction: column;
  gap: var(--space-m);
}

/* Desktop: side-by-side */
@media (width >= 900px) {
  .columns > div {
    flex-direction: row;
  }

  .columns > div > div {
    flex: 1;  /* Equal width columns */
  }

  /* Image-only columns don't stretch */
  .columns > div > div.columns-img-col {
    flex: 0 0 auto;
  }
}

/* Specific column widths */
.columns.columns-3-cols > div > div {
  flex-basis: 33.33%;
}
The Flow Summary:
  1. Author creates a table with multiple columns (cells) in a single row
  2. AEM converts each cell to a sibling <div> within a row container
  3. JavaScript counts columns (adds columns-N-cols) and detects image-only columns
  4. CSS uses flexbox to create responsive layouts: stacked on mobile, side-by-side on desktop

Why This Pattern Works

The columns block demonstrates key AEM Edge Delivery principles:

  • Content-driven: Column count is detected automatically, not configured
  • Semantic HTML: JavaScript adds meaningful classes based on content analysis
  • Mobile-first: Default stacked layout, enhanced for larger screens
  • Flexible: Works with any content type (text, images, headings, etc.)

JavaScript Logic

Create blocks/columns/columns.js:

export default function decorate(block) {
  const cols = [...block.firstElementChild.children];
  block.classList.add(`columns-${cols.length}-cols`);

  // Setup image columns
  [...block.children].forEach((row) => {
    [...row.children].forEach((col) => {
      const pic = col.querySelector('picture');
      if (pic) {
        const picWrapper = pic.closest('div');
        if (picWrapper && picWrapper.children.length === 1) {
          // Picture is only content in column
          picWrapper.classList.add('columns-img-col');
        }
      }
    });
  });
}

How It Works

Column Counting

const cols = [...block.firstElementChild.children];
block.classList.add(`columns-${cols.length}-cols`);

Counts children of the first row and adds a class like columns-3-cols for CSS targeting.

Image Detection

const pic = col.querySelector('picture');
if (pic) {
  const picWrapper = pic.closest('div');
  if (picWrapper && picWrapper.children.length === 1) {
    picWrapper.classList.add('columns-img-col');
  }
}

Checks if a column contains ONLY a picture (no other content). These columns get special styling to prevent stretching.

Best Practices

Content

  • Balance: Keep column heights similar for better visual balance
  • Readability: Limit text columns to 2-3 on desktop for optimal reading width
  • Mobile-first: Design for stacked mobile layout first

Images

  • Consistent aspect ratios: Use same ratio across image columns
  • Optimize: Right-size images for column width (not full-width)
  • Alt text: Always provide descriptive alt text

Responsive Design

  • Test breakpoints: Verify stack/unstack behavior at 900px
  • Content order: Most important content should be first (appears top on mobile)
  • Max columns: Avoid more than 4 columns on desktop (readability)
