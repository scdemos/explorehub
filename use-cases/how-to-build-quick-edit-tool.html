How to Build a Quick Edit Tool

Enable in-context editing with live preview and real-time collaboration using DA Live's Quick Edit module

Authoring Tool Live Editing Yjs/CRDT Intermediate

Overview

Quick Edit is a powerful authoring tool that transforms static web pages into live, editable documents. It provides authors with an in-context editing experience where they can modify content directly on the page while seeing a real-time preview. The tool uses collaborative editing technology (Yjs) to support multiple authors working on the same content simultaneously.

What You'll Build:
  • Quick Edit Loader: Module that bootstraps the DA Live Quick Edit interface
  • Import Map Configuration: Setup for Lit and Yjs dependencies
  • Sidekick Integration: Event-driven activation via AEM Sidekick
  • URL Parameter Activation: Direct page access with ?quick-edit parameter
  • Environment Detection: Support for local, branch, and production editing
Prerequisites:
  • Understanding of AEM Sidekick architecture
  • Familiarity with ES modules and dynamic imports
  • Knowledge of Yjs collaborative editing (optional)
  • Experience with Lit web components (optional)

Architecture

Quick Edit uses a lightweight loader pattern that dynamically imports the full editing interface from DA Live. This keeps your codebase minimal while providing a complete editing experience:

Key Components

  • Loader Module: Minimal bootstrapper (quick-edit.js) that detects environment and loads the full editor
  • Import Map: Defines module dependencies (Lit, Yjs wrapper) for ESM resolution
  • Environment Detector: Determines correct DA Live origin (production, local, branch)
  • Payload Generator: Constructs configuration object with mountpoint and location
  • DA Live Module: Full editing interface loaded from https://da.live/nx/public/plugins/quick-edit/quick-edit.js
  • Page Reloader: Passes loadPage() function to reload content after edits

File Structure

The Quick Edit tool requires minimal local code:

tools/quick-edit/

Why This Structure:
  • Minimal footprint: Only 54 lines of loader code in your repository
  • Always up-to-date: Full editor loaded from DA Live ensures latest features
  • No maintenance: Bug fixes and enhancements automatically available
  • Flexible environments: Easy switching between production, local dev, and branch previews

Implementation

Step 1: Create the Quick Edit Loader

Create tools/quick-edit/quick-edit.js with the loader logic:

// eslint-disable-next-line import/no-cycle
import { loadPage } from '../../scripts/scripts.js';

// Import map for module dependencies
const importMap = {
  imports: {
    'da-lit': 'https://da.live/deps/lit/dist/index.js',
    'da-y-wrapper': 'https://da.live/deps/da-y-wrapper/dist/index.js',
  },
};

/**
 * Adds import map to document head for module resolution
 */
function addImportmap() {
  const importmapEl = document.createElement('script');
  importmapEl.type = 'importmap';
  importmapEl.textContent = JSON.stringify(importMap);
  document.head.appendChild(importmapEl);
}

/**
 * Dynamically loads the Quick Edit module from DA Live
 * @param {string} origin - DA Live origin URL
 * @param {Object} payload - Configuration payload with mountpoint and location
 */
async function loadModule(origin, payload) {
  const { default: loadQuickEdit } = await import(`${origin}/nx/public/plugins/quick-edit/quick-edit.js`);
  document.querySelector('html').setAttribute('quick-edit', 'true');
  loadQuickEdit(payload, loadPage);
}

/**
 * Generates Sidekick-compatible payload from current location
 * @returns {Object} Payload object with config and location
 */
function generateSidekickPayload() {
  let { hostname } = window.location;

  // Handle localhost dev environment
  if (hostname === 'localhost') {
    hostname = document.querySelector('meta[property="hlx:proxyUrl"]').content;
  }

  // Parse hostname: branch--repo--owner.aem.page
  const parts = hostname.split('.')[0].split('--');
  const [, repo, owner] = parts;

  return {
    detail: {
      config: {
        mountpoint: `https://content.da.live/${owner}/${repo}/`
      },
      location: {
        pathname: window.location.pathname,
      },
    }
  };
}

/**
 * Initializes Quick Edit with environment detection
 * @param {Object} payload - Optional custom payload (uses generated if not provided)
 */
export default function init(payload) {
  const { search } = window.location;
  const ref = new URLSearchParams(search).get('quick-edit');

  // Determine DA Live origin based on ref parameter
  let origin;
  if (ref === 'on' || !ref) {
    origin = 'https://da.live'; // Production
  } else if (ref === 'local') {
    origin = 'http://localhost:6456'; // Local development
  } else {
    origin = `https://${ref}--da-nx--adobe.aem.live`; // Branch preview
  }

  addImportmap();
  loadModule(origin, payload || generateSidekickPayload());
}

Step 2: Integrate with Page Scripts

Add Sidekick integration and URL parameter detection to scripts/scripts.js:

// In your loadLazy() or delayed() function:

/**
 * Lazy loader for Quick Edit module
 */
const loadQuickEdit = async (...args) => {
  const { default: initQuickEdit } = await import('../tools/quick-edit/quick-edit.js');
  initQuickEdit(...args);
};

/**
 * Sets up Sidekick event listeners for Quick Edit
 * @param {HTMLElement} sk - Sidekick element
 */
const addSidekickListeners = (sk) => {
  sk.addEventListener('custom:quick-edit', loadQuickEdit);
};

// Wait for Sidekick to be ready
const sk = document.querySelector('aem-sidekick');
if (sk) {
  addSidekickListeners(sk);
} else {
  // Wait for sidekick to be loaded
  document.addEventListener('sidekick-ready', () => {
    addSidekickListeners(document.querySelector('aem-sidekick'));
  }, { once: true });
}

// At the end of scripts.js (outside any function):

/**
 * Auto-activate Quick Edit if URL parameter present
 */
const IS_QUICK_EDIT = new URL(window.location.href).searchParams.has('quick-edit');
if (IS_QUICK_EDIT) {
  import('../tools/quick-edit/quick-edit.js').then((mod) => mod.default());
}

How It Works

1. Activation Flow

sequenceDiagram
    participant Author
    participant Page
    participant Sidekick
    participant Loader
    participant DA_Live
    participant Editor

    Author->>Page: Open page
    Page->>Sidekick: Load Sidekick
    Sidekick-->>Page: sidekick-ready event
    Page->>Sidekick: Register event listener

    Note over Author,Sidekick: Option 1: Sidekick Button
    Author->>Sidekick: Click Quick Edit
    Sidekick->>Page: Dispatch custom:quick-edit
    Page->>Loader: loadQuickEdit()

    Note over Author,Page: Option 2: URL Parameter
    Author->>Page: Open with ?quick-edit
    Page->>Loader: Auto-init

    Loader->>Loader: addImportmap()
    Loader->>DA_Live: Import module
    DA_Live-->>Loader: loadQuickEdit function
    Loader->>Editor: Initialize with payload
    Editor->>Page: Inject editing UI

2. Environment Detection

The loader automatically detects which DA Live environment to use:

  • Production: ?quick-edit or ?quick-edit=on → https://da.live
  • Local development: ?quick-edit=local → http://localhost:6456
  • Branch preview: ?quick-edit=my-branch → https://my-branch--da-nx--adobe.aem.live

3. Payload Generation

The payload provides Quick Edit with context about the current page:

{
  detail: {
    config: {
      mountpoint: "https://content.da.live/owner/repo/"
    },
    location: {
      pathname: "/path/to/page"
    }
  }
}

This tells Quick Edit:

  • mountpoint: Where to read/write content (DA content API)
  • pathname: Which document to edit

4. Import Map Resolution

The import map allows DA Live's module to resolve its dependencies:

  • da-lit: Lit web components library for UI
  • da-y-wrapper: Yjs wrapper for collaborative editing (CRDT)

Without the import map, the browser wouldn't know where to find these bare module specifiers.

Collaborative Editing

  4. Conflicts resolved automatically

Custom loadPage Implementation

Quick Edit calls loadPage() after edits to refresh content. Customize this if you have special reload logic:

import { loadPage as defaultLoadPage } from '../../scripts/scripts.js';

async function customLoadPage() {
  // Clear caches
  if ('caches' in window) {
    const cacheKeys = await caches.keys();
    await Promise.all(cacheKeys.map((key) => caches.delete(key)));
  }

  // Reload with custom logic
  await defaultLoadPage();

  // Re-initialize custom components
  document.querySelectorAll('[data-custom-component]').forEach((el) => {
    // Re-decorate
  });
}

async function loadModule(origin, payload) {
  const { default: loadQuickEdit } = await import(`${origin}/nx/public/plugins/quick-edit/quick-edit.js`);
  document.querySelector('html').setAttribute('quick-edit', 'true');
  loadQuickEdit(payload, customLoadPage); // Use custom function
}

Troubleshooting

Common Issues

Quick Edit doesn't load

  • Check console: Look for CORS errors or 404s when importing from DA Live
  • Verify URL parameter: Ensure ?quick-edit is present in URL
  • Check network: Verify connection to https://da.live
  • Inspect import map: Confirm <script type="importmap"> was added before dynamic import

Localhost detection fails

  • Check meta tag: Ensure <meta property="hlx:proxyUrl"> exists with correct hostname
  • Verify AEM CLI: Confirm you're running aem up or equivalent local server

Module resolution errors

  • Import map timing: Ensure addImportmap() is called before loadModule()
  • Check URLs: Verify import map URLs are accessible and returning valid JavaScript

Changes not saving

  • Check mountpoint: Verify mountpoint URL is correct and accessible
  • Verify permissions: Ensure user has write access to the content repository
  • Check payload: Log payload object to verify config and location are correct

4. Performance Optimization

Lazy load Quick Edit dependencies only when needed:

let quickEditLoaded = false;

export default async function init(payload) {
  if (quickEditLoaded) {
    console.log('Quick Edit already loaded');
    return;
  }

  // Show loading indicator
  const loader = document.createElement('div');
  loader.className = 'quick-edit-loader';
  loader.textContent = 'Loading Quick Edit...';
  document.body.appendChild(loader);

  try {
    const { search } = window.location;
    const ref = new URLSearchParams(search).get('quick-edit');

    let origin;
    if (ref === 'on' || !ref) origin = 'https://da.live';
    if (ref === 'local') origin = 'http://localhost:6456';
    if (!origin) origin = `https://${ref}--da-nx--adobe.aem.live`;

    addImportmap();
    await loadModule(origin, payload || generateSidekickPayload());

    quickEditLoaded = true;
  } catch (error) {
    console.error('Failed to load Quick Edit:', error);
    alert('Failed to activate Quick Edit. Please try again.');
  } finally {
    loader.remove();
  }
}

Best Practices

Performance

  • Lazy loading: Only import Quick Edit when activated (not on page load)
  • Import map timing: Add import map synchronously before dynamic import
  • Cache strategy: Allow browser to cache DA Live modules for repeat visits

Security

  • Permission checks: Verify user has edit rights before enabling Quick Edit
  • CORS configuration: Ensure DA Live origin is allowed in CSP
  • Token validation: Quick Edit handles auth via DA Live, but verify tokens on save

User Experience

  • Loading indicators: Show feedback while Quick Edit module loads
  • Error handling: Provide clear messages when activation fails
  • State preservation: Ensure page state is maintained after edits

Development

  • Local testing: Use ?quick-edit=local with local DA Live for development
  • Branch testing: Test Quick Edit changes on branch previews before merging
  • Version pinning: Consider pinning DA Live version for stability (e.g., /v1.2.3/nx/public/plugins/...)
