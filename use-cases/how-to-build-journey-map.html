How to Build a Journey Map Block

Step-by-step accordion interface with locked progression

Block Interactive Advanced

Overview

The Journey Map block creates an interactive accordion interface where users progress through sequential steps. Each step must be completed before unlocking the next, making it perfect for onboarding flows, tutorials, checklists, and guided workflows.

Key Features

  • Sequential unlocking - Complete step to unlock next
  • Visual progress bar with animated dots
  • Accordion expand/collapse interface
  • State management (pending → active → complete)
  • Responsive mobile/desktop layouts
  • Universal Editor support

How It Works

Step 1: Build Steps from Table Rows

The buildStep() function (journey-map.js:167-215) transforms each row into a step object:

function buildStep(row, index) {
  const [titleSource, contentSource] = row.children;

  // Extract title (use existing heading or create h3)
  const titleText = titleSource.textContent.trim() || `Step ${index + 1}`;
  const title = createTag('h3', { class: 'journey-map-step-title' });

  // Build content container
  const content = createTag('div', { class: 'journey-map-step-content' });
  content.append(...contentSource.childNodes);

  // Create toggle button (accordion header)
  const toggle = createTag('button', {
    type: 'button',
    class: 'journey-map-step-toggle',
    'aria-expanded': 'false',
  });

  // Assemble step article
  const step = createTag('article', {
    class: 'journey-map-step',
    'data-step-index': String(index),
  }, [toggle, content]);

  return { step, toggle, content, titleText };
}

Step 2: Create Progress Bar

Build visual progress indicators with dots and connectors (journey-map.js:247-259):

const checkpoints = steps.map(({ titleText }) => {
  const dot = createTag('span', {
    class: 'journey-map-progress-dot',
    'aria-hidden': 'true'
  });
  const item = createTag('li', {
    class: 'journey-map-progress-item',
    'aria-label': titleText,
  }, [dot]);
  return { item, dot };
});

Step 3: State Management

Track current and highest reached step (journey-map.js:269-271):

let currentStep = -1;          // Currently expanded step
let highestStepReached = -1;   // Highest unlocked step

// Visual classes applied:
.is-active      // Currently expanded
.is-complete    // Completed (step ≤ highestStepReached)
.is-upcoming    // Locked (step > highestStepReached + 1)

Step 4: Update UI Function

Single function handles all UI updates (journey-map.js:280-337):

function update() {
  // Calculate progress percentage
  const completeCount = Math.max(0, highestStepReached + 1);
  const progressRatio = completeCount / steps.length;
  progress.style.setProperty('--journey-progress', String(progressRatio));

  // Update each step's state
  steps.forEach(({ step, toggle, content }, index) => {
    step.classList.remove('is-active', 'is-complete', 'is-upcoming');
    if (index <= highestStepReached) step.classList.add('is-complete');
    if (index === currentStep) step.classList.add('is-active');
    if (index > highestStepReached) step.classList.add('is-upcoming');

    // Show/hide content
    content.hidden = (index !== currentStep);
    toggle.setAttribute('aria-expanded', isCurrent ? 'true' : 'false');
    toggle.disabled = (index > highestStepReached + 1);
  });

  // Update progress dots
  checkpoints.forEach(({ item, dot }, index) => {
    if (index <= highestStepReached) item.classList.add('is-complete');
    if (index === currentStep) item.classList.add('is-active');
  });
}

Key Implementation Details

  • No dependencies - Pure vanilla JavaScript, no external libraries
  • Event handlers - Click listeners on each toggle button
  • Universal Editor - moveInstrumentation() preserves edit capabilities
  • Responsive - CSS uses @media (width >= 900px) for desktop layout
  • CSS custom properties - --journey-progress for dynamic progress width
  • Smooth animations - Transform-based chevron rotation, opacity transitions

Accessibility & Performance

Accessibility Features

ARIA Attributes

  • aria-expanded - Toggle state (true when expanded)
  • aria-disabled - Locked steps (true when locked)
  • aria-current="step" - Active step marker
  • aria-label - Progress navigation context
  • aria-hidden="true" - Decorative icons

Semantic HTML

  • <article> for each step
  • <nav> for progress bar
  • <button type="button"> for toggles
  • Heading hierarchy preserved

Keyboard Navigation

  • Tab - Navigate toggles
  • Enter / Space - Activate toggle
  • Disabled steps cannot receive focus
Performance Optimizations

Load Performance

  • 152 lines JS - Minimal JavaScript, no libraries
  • 228 lines CSS - Mobile-first, scoped selectors
  • Lazy execution - Decorate runs after viewport intersection
  • No external deps - Native browser APIs only

Runtime Performance

  • Single update function - Batched DOM updates
  • Minimal reflows - State changes grouped
  • GPU animations - CSS transform for chevron
  • Media query caching - window.matchMedia()

CSS Performance

  • Custom properties - --journey-progress for width
  • Transform animations - GPU-accelerated
  • Scoped styles - All prefixed with .journey-map
Advanced Customization

Unlock All Steps

// In update(), change locking logic:
const isUnlocked = true; // Allow all steps

// Or custom logic:
const isUnlocked = steps[index - 1]?.completed || index === 0;

Save Progress with localStorage

// After state init:
const saved = localStorage.getItem('journey-progress');
if (saved) {
  const { current, highest } = JSON.parse(saved);
  currentStep = current;
  highestStepReached = highest;
}

// In toggle handler:
localStorage.setItem('journey-progress', JSON.stringify({
  current: currentStep,
  highest: highestStepReached,
}));

Custom Events

// Dispatch event after update:
block.dispatchEvent(new CustomEvent('journey-step-change', {
  detail: { step: index, completed: highestStepReached },
  bubbles: true,
}));
