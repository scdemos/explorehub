How to Build an Auth Toggle Block

Floating preview panel for testing authenticated vs. anonymous content views

Block Testing Intermediate

Overview

The Auth Toggle block creates a floating panel for content authors and developers to preview gated content in both authenticated and anonymous states without needing to log in/out. It appears as a fixed handle on the right side of the page that expands into a control panel.

Key Features:

  • Only appears on gated pages (via isGatedPage() check)
  • Fixed position floating panel at bottom-right corner
  • Expandable handle with "AUTH STATE" label
  • Shows current state (Authenticated or Anonymous)
  • One-click switching between states via query parameter (?auth=true/false)
  • Click-outside-to-close behavior
  • Accessible with ARIA attributes and keyboard support
  • Smooth animations and bounce effect on load
  • Auto-removes itself on non-gated pages

How It Works

The Auth Toggle follows this workflow:

graph TD A[Page Loads] --> B{Is Gated Page?} B -->|No| C[Remove Block] B -->|Yes| D[Read ?auth Query Param] D --> E{auth=true?} E -->|Yes| F[Current State: Authenticated] E -->|No| G[Current State: Anonymous] F --> H[Render Panel with Switch to Anonymous] G --> I[Render Panel with Switch to Authenticated] H --> J[Show Floating Handle] I --> J J --> K[User Clicks Handle] K --> L[Expand Panel] L --> M[User Clicks Switch Button] M --> N[Update ?auth Query Param] N --> O[Reload Page]

Authentication State Logic:

  1. Check Gated Page: Use isGatedPage() utility to determine if auth toggle should appear
  2. Read Query Param: Check ?auth=true or ?auth=false in URL
  3. Display Current State: Show indicator for current authentication state
  4. Toggle State: When user switches, update query param and reload page

import { loadCSS } from '../../scripts/aem.js';
import { createTag } from '../../scripts/shared.js';
import { isGatedPage } from '../../scripts/shared.js';

const CSS_CLASSES = {
  TOGGLE: 'auth-toggle',
  HANDLE: 'auth-handle',
  HANDLE_ICON: 'auth-handle-icon',
  HEADER: 'auth-header',
  CLOSE: 'auth-close',
  OPTIONS: 'auth-options',
  OPTION_BUTTON: 'auth-option-button',
  EXPANDED: 'expanded',
  HIDDEN: 'hidden',
  VISIBLE: 'visible',
  BOUNCE: 'bounce',
  CURRENT_STATE: 'current-state',
  AUTHENTICATED: 'authenticated',
  ANONYMOUS: 'anonymous',
};

function getAuthState() {
  const authValue = new URLSearchParams(window.location.search).get('auth');
  return authValue === 'true';
}

export default function decorate(block) {
  if (!isGatedPage()) {
    block.remove();
    return block;
  }

  const currentState = getAuthState();
  let isExpanded = false;

  block.innerHTML = '';
  block.id = CSS_CLASSES.TOGGLE;
  block.classList.add(CSS_CLASSES.TOGGLE);

  const handleIcon = createTag('div', { class: CSS_CLASSES.HANDLE_ICON }, 'AUTH STATE');
  const handle = createTag('button', {
    type: 'button',
    class: CSS_CLASSES.HANDLE,
    title: 'Open or close auth preview',
    'aria-label': 'Auth preview panel',
    'aria-expanded': 'false',
  }, handleIcon);

  const headerText = createTag('span', {}, 'Auth State');
  const closeBtn = createTag('button', {
    class: CSS_CLASSES.CLOSE,
    type: 'button',
    'aria-label': 'Close auth panel',
  }, 'x');
  const header = createTag('div', { class: CSS_CLASSES.HEADER }, [headerText, closeBtn]);

  const panelBody = createTag('div', { class: 'auth-toggle-body', id: \`\${block.id || CSS_CLASSES.TOGGLE}-panel\` });
  panelBody.setAttribute('role', 'region');
  panelBody.setAttribute('aria-label', 'Auth preview');
  handle.setAttribute('aria-controls', panelBody.id);

  const optionsContainer = createTag('div', { class: CSS_CLASSES.OPTIONS });
  const currentStateIndicator = createTag('div', {
    class: \`\${CSS_CLASSES.OPTION_BUTTON} \${CSS_CLASSES.CURRENT_STATE}\`,
  }, currentState ? 'Authenticated' : 'Anonymous');

  const switchButton = createTag('button', {
    class: CSS_CLASSES.OPTION_BUTTON,
    type: 'button',
    'data-auth-state': currentState ? CSS_CLASSES.ANONYMOUS : CSS_CLASSES.AUTHENTICATED,
  }, currentState ? 'Switch to Anonymous' : 'Switch to Authenticated');

  optionsContainer.append(currentStateIndicator, switchButton);
  panelBody.append(header, optionsContainer);

  function handleClickOutside(event) {
    if (block.contains(event.target)) return;
    if (isExpanded) {
      isExpanded = false;
      block.classList.remove(CSS_CLASSES.EXPANDED);
      handle.classList.remove(CSS_CLASSES.HIDDEN);
      handle.setAttribute('aria-expanded', 'false');
      document.removeEventListener('click', handleClickOutside);
    }
  }

  function togglePanel() {
    isExpanded = !isExpanded;
    block.classList.toggle(CSS_CLASSES.EXPANDED, isExpanded);
    handle.classList.toggle(CSS_CLASSES.HIDDEN, isExpanded);
    handle.setAttribute('aria-expanded', isExpanded ? 'true' : 'false');
    if (isExpanded) {
      setTimeout(() => {
        document.addEventListener('click', handleClickOutside);
      }, 100);
    } else {
      document.removeEventListener('click', handleClickOutside);
    }
  }

  function handleOptionClick(targetState) {
    const url = new URL(window.location.href);
    if (targetState === CSS_CLASSES.AUTHENTICATED) {
      url.searchParams.set('auth', 'true');
    } else if (targetState === CSS_CLASSES.ANONYMOUS) {
      url.searchParams.set('auth', 'false');
    }
    window.location.href = url.toString();
  }

  handle.addEventListener('click', (e) => {
    e.stopPropagation();
    togglePanel();
  });
  closeBtn.addEventListener('click', togglePanel);
  switchButton.addEventListener('click', () => {
    handleOptionClick(switchButton.getAttribute('data-auth-state'));
  });

  block.append(handle, panelBody);

  block.cleanup = () => {
    document.removeEventListener('click', handleClickOutside);
  };

  requestAnimationFrame(() => {
    block.classList.add(CSS_CLASSES.VISIBLE);
    setTimeout(() => {
      handle.classList.add(CSS_CLASSES.BOUNCE);
      setTimeout(() => handle.classList.remove(CSS_CLASSES.BOUNCE), 400);
    }, 300);
  });

  return block;
}

export async function createAuthToggle() {
  if (!isGatedPage()) return undefined;

  await loadCSS(\`\${window.hlx.codeBasePath}/blocks/auth-toggle/auth-toggle.css\`);
  const block = createTag('div', { class: CSS_CLASSES.TOGGLE });
  document.body.append(block);
  return decorate(block);
}

Document Authoring

The Auth Toggle block is typically not added by content authors in documents. Instead, it's programmatically injected into gated pages via the createAuthToggle() export function.

Auth Toggle

Programmatic integration in this demo:

The auth toggle is not wired directly from scripts.js. It is created by scripts/utils/gated-content.js, which gates the toggle on both isGatedPage() AND isAuthorEnvironment() (so it never appears in production):

// scripts/utils/gated-content.js
import { createAuthToggle } from '../../blocks/auth-toggle/auth-toggle.js';
import { isGatedPage } from '../shared.js';

function isAuthorEnvironment() {
  const host = window.location.hostname;
  return host.includes('localhost')
    || host.includes('aem.page')
    || host.includes('aem.reviews')
    || host.endsWith('.ue.da.live')
    || host.endsWith('.stage-ue.da.live');
}

async function createAuthorToggle() {
  if (!isAuthorEnvironment() || !isGatedPage()) return undefined;
  return createAuthToggle();
}

function initContentProtection() {
  if (!isAuthorEnvironment() || !isGatedPage()) return;
  if (document.readyState === 'loading') {
    document.addEventListener('DOMContentLoaded', async () => {
      applyContentProtection();    // hides logged-in/logged-out sections in author env
      await createAuthorToggle();  // injects the floating panel
    }, { once: true });
    return;
  }
  applyContentProtection();
  createAuthorToggle();
}

scripts/scripts.js calls initContentProtection() from loadLazy. There is no direct call to createAuthToggle() from scripts.js; that helper is invoked through createAuthorToggle() in the gated-content utility.

Why two layers? Production gating happens server-side in workers/cdn/handlers/gating.js. The toggle and applyContentProtection() only run in author/preview environments — they exist solely so authors can preview both states without logging in to Cloudflare Access.

Gated Page Detection

isGatedPage() lives in scripts/shared.js and uses getMetadata from aem.js:

// scripts/shared.js
import { getMetadata } from './aem.js';

export function isGatedPage() {
  return String(getMetadata('gated') || '').trim().toLowerCase() === 'true';
}

To mark a page as gated, add <meta name="gated" content="true"> to the document (typically via Page Metadata in DA / Word).

Accessibility

  • ARIA attributes: aria-expanded, aria-controls, aria-label for screen readers
  • Semantic buttons: the handle and switch are real <button type="button"> elements; Tab/Enter work natively
  • Click-outside: a delayed document.click listener collapses the panel when clicked outside the block
  • Role region: panel body has role="region" for landmark navigation
  • Visual feedback: bounce animation on first appearance, hover offset on the handle, color-coded current-state pill

Note: the demo source does not implement an Escape handler. If you need it, listen for keydown on the panel and call the existing togglePanel() when e.key === 'Escape'.

Best Practices

  • Author/Developer Only: This tool should only appear for authors and developers, not end users
  • Environment Detection: Consider hiding in production or for non-authenticated authors
  • Query Param Strategy: Use ?auth=true/false to avoid cookie complexity
  • Cleanup Handlers: Remove event listeners on block removal to prevent memory leaks
  • Fixed Positioning: Use z-index high enough to appear above all content but not navigation
  • Mobile Support: Panel width uses min() to adapt to small screens
  • Safe Area Insets: Respect device safe areas (notches, home indicators)
  • Visual Distinction: Use distinct color (rust/orange) to indicate it's a dev tool

Quick Start

  1. Create block files: 
    mkdir -p blocks/auth-toggle
touch blocks/auth-toggle/auth-toggle.js
touch blocks/auth-toggle/auth-toggle.css
  2. Add isGatedPage() to scripts/shared.js: 
    import { getMetadata } from './aem.js';
export function isGatedPage() {
  return String(getMetadata('gated') || '').trim().toLowerCase() === 'true';
}
  3. Copy the JavaScript and CSS code from the Implementation section above into blocks/auth-toggle/.
  4. Add the gated-content utility at scripts/utils/gated-content.js with isAuthorEnvironment(), applyContentProtection(), and initContentProtection() (see demo source).
  5. Wire into scripts/scripts.js: 
    import { initContentProtection } from './utils/gated-content.js';

async function loadLazy(doc) {
  // ... existing lazy work
  initContentProtection();
}
  6. Mark pages as gated: add gated: true to the page's metadata table (renders as <meta name="gated" content="true">).
  7. Test locally: 
    aem up
    Navigate to a gated page and verify the auth toggle appears
  8. Test switching: Click handle, then switch between authenticated/anonymous states
