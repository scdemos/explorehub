How to Build a Dynamic Forms Block

Complete implementation guide for building JSON-driven forms with validation, conditional logic, and remote submission

Block Forms Advanced

Overview

The Forms block creates dynamic forms from JSON definitions, supporting text inputs, textareas, selects, radio/checkbox groups, toggles, conditional fields, validation, and remote submission. Perfect for contact forms, lead generation, feedback, and surveys.

View Live Demo Author Perspective Official Docs

Key Features

  • JSON-Driven: Form structure defined in JSON, fetched at runtime
  • Field Types: text, email, tel, number, textarea, select, radio, checkbox, toggle
  • Conditional Logic: Show/hide fields based on other field values
  • Validation: Built-in HTML5 validation with custom messages
  • Remote Submission: POST to any endpoint (Cloudflare Workers, App Builder, etc.)
  • Thank You Pages: Load fragment content after successful submission
  • Accessibility: ARIA attributes, keyboard navigation, screen reader support

Conditional Fields

Show/hide fields based on other field values using the conditional property:

Complete Example with Conditional Logic
Form with conditional fields 
{
  "data": [
    {
      "field": "Contact Method",
      "label": "How should we contact you?",
      "type": "radio",
      "options": "Email, Phone",
      "required": "true"
    },
    {
      "field": "Email Address",
      "label": "Your Email",
      "type": "email",
      "required": "true",
      "conditional": "contactMethod-email",
      "help": "We'll respond within 24 hours"
    },
    {
      "field": "Phone Number",
      "label": "Your Phone",
      "type": "tel",
      "required": "true",
      "conditional": "contactMethod-phone",
      "help": "Include country code"
    },
    {
      "field": "Submit",
      "type": "submit",
      "label": "Submit"
    }
  ]
}

How it works:

  • conditional: "contactMethod-email" means show this field when "Contact Method" equals "Email"
  • Format: {controllerFieldName}-{value} (converted to camelCase)
  • Controlled fields are hidden by default until condition is met
  • required is dynamically toggled based on visibility
  • Hidden fields removed from tab order (tabindex="-1")

Step 1: Form Loading

The form block uses Intersection Observer for lazy loading:

Form Loading Code
form.js - Main decorate function (lines 733-767) 
export default function decorate(block) {
  // Hide block until form is ready
  block.style.visibility = 'hidden';

  // Extract form definition URL and submit endpoint
  const [source, submit] = [...block.querySelectorAll('a[href]')].map((a) => a.href);

  if (source) {
    // Use Intersection Observer to load form when visible
    const observer = new IntersectionObserver((entries) => {
      entries.forEach(async (entry) => {
        if (entry.isIntersecting) {
          try {
            // Fetch form definition JSON
            const resp = await fetch(new URL(source, window.location.origin));
            if (!resp.ok) throw new Error(`${resp.status}: ${resp.statusText}`);

            const json = await resp.json();

            // Handle different JSON formats (data, fields, or top-level array)
            const raw = json.data ?? json.fields ?? json;
            const data = Array.isArray(raw) ? raw : (raw?.fields && Array.isArray(raw.fields) ? raw.fields : null);

            if (!data || !Array.isArray(data)) {
              throw new Error(`No form fields at ${source}`);
            }

            // Build form from field definitions
            const form = buildForm(data, submit);

            // Replace block content with form
            block.replaceChildren(form);
            block.removeAttribute('style');
          } catch (error) {
            console.error('Could not build form from', source, error);
            block.parentElement.remove();
          }

          observer.disconnect();
        }
      });
    }, { threshold: 0 });

    observer.observe(block);
  } else {
    console.error('Unable to create form without source');
    block.parentElement.remove();
  }
}

Key Points:

  • Lazy loads form definition when block enters viewport
  • Supports multiple JSON formats for flexibility
  • Removes block entirely if form fails to load
  • Initial visibility hidden prevents content flash

Step 2: Building Form Elements

Each field type has a dedicated builder function:

Field Builders
form.js - Build input (lines 61-74) 
function buildInput(field) {
  const {
    type, field: fieldName, required, default: defaultValue, placeholder,
  } = field;

  const input = createElement('input');
  input.type = type || 'text';
  input.id = generateId(fieldName);    // Converts to camelCase
  input.name = input.id;
  input.required = required === 'true';  // String comparison
  if (defaultValue) input.value = defaultValue;
  if (placeholder) input.placeholder = placeholder;
  return input;
}
form.js - Build select (lines 183-228) 
function buildSelect(field, controlled) {
  const {
    type, options, field: fieldName, label, required, placeholder,
  } = field;
  if (!options) return null;

  const wrapper = createElement('div', `form-field ${type}-field`);

  // Add controller/condition data attributes for conditional logic
  if (controlled) {
    const controller = controlled.split('-')[0];
    wrapper.dataset.controller = controller;
    wrapper.dataset.condition = controlled;
  }

  wrapper.append(buildLabel(label, 'label', generateId(fieldName), required === 'true'));

  const select = createElement('select');
  select.id = generateId(fieldName);
  select.name = select.id;
  select.required = required === 'true';
  wrapper.append(select);

  // Add placeholder option if specified
  if (placeholder) {
    const placeholderOption = createElement('option');
    placeholderOption.value = '';
    placeholderOption.textContent = placeholder;
    placeholderOption.disabled = true;
    placeholderOption.selected = true;
    select.append(placeholderOption);
  }

  // Try to parse options as URL for remote loading
  try {
    const url = new URL(options);
    buildOptionsFromUrl(url).then((os) => {
      select.append(...os);
    });
  } catch (error) {
    // Not a URL - treat as comma-separated list
    options.split(',').forEach((o) => {
      const option = o.trim();
      const optionEl = createElement('option');
      optionEl.value = option;
      optionEl.textContent = option;
      select.append(optionEl);
    });
  }

  return wrapper;
}

Step 3: Conditional Logic

Controller/controlled relationships enable dynamic field visibility:

Conditional Logic Implementation
form.js - Toggle conditional (lines 284-308) 
function toggleConditional(e, controllerConfig) {
  const { target } = e;
  const controller = target.name;

  // Check if this is a controlling input
  if (controllerConfig.has(controller)) {
    const inputs = [...controllerConfig.get(controller)];

    inputs.forEach((i) => {
      const field = i.closest('.form-field');
      const { condition } = field.dataset;

      // Check if condition is met (e.g., "contactMethod-email")
      const conditionMet = condition.includes(toClassName(target.value));

      // Toggle visibility
      field.setAttribute('aria-hidden', !conditionMet);

      // Toggle required and tabindex based on visibility
      if (conditionMet) {
        // Restore original required state
        if (i.dataset.originalRequired === 'true') {
          i.setAttribute('required', '');
        }
        i.removeAttribute('tabindex');
      } else {
        // Remove required and exclude from tab order
        i.removeAttribute('required');
        i.setAttribute('tabindex', '-1');
      }
    });
  }
}

How it works:

  1. On form load, build map of controller → controlled fields
  2. Set initial visibility based on default values
  3. Listen for change events on form
  4. When controller changes, check all controlled fields
  5. Show field if condition matches, hide otherwise
  6. Dynamically toggle required and tabindex

Step 4: Form Submission

Submission validates, generates payload, POSTs to endpoint, and shows confirmation:

Submission Handler
form.js - Handle submit (lines 534-575) 
async function handleSubmit(form) {
  const status = form.querySelector('.form-status');
  const setStatus = (msg) => { if (status) status.textContent = msg; };

  try {
    // Generate payload from form data
    const payload = generatePayload(form);
    const body = { data: payload };

    // Disable form during submission
    toggleForm(form);
    setStatus('Sending...');

    // POST to remote endpoint
    const response = await fetch(form.dataset.action, {
      method: 'POST',
      body: JSON.stringify(body),
      headers: {
        'Content-Type': 'application/json',
      },
    });

    if (response.ok) {
      // Check for thank you page configuration
      if (form.dataset.confirmation) {
        const replaced = await replaceWithThankYou(form, form.dataset.confirmation);
        if (!replaced) {
          // Fallback if fragment fails
          setStatus('Thanks! Your message has been sent.');
          form.reset();
        }
      } else {
        // No thank you page - show inline message
        setStatus('Thanks! Your message has been sent.');
        form.reset();
      }
    } else {
      const error = await response.text();
      throw new Error(error);
    }
  } catch (error) {
    setStatus('Unable to submit right now. Please try again.');
    console.error(error);
  } finally {
    // Re-enable form
    toggleForm(form, false);
  }
}
form.js - Generate payload (lines 447-461) 
function generatePayload(form) {
  const payload = {};

  [...form.elements].forEach((field) => {
    if (field.name && !field.disabled) {
      if (field.type === 'radio') {
        // Only include checked radio
        if (field.checked) payload[field.name] = field.value;
      } else if (field.type === 'checkbox') {
        // Concatenate checked checkboxes
        if (field.checked) {
          payload[field.name] = payload[field.name]
            ? `${payload[field.name]},${field.value}`
            : field.value;
        }
      } else {
        // All other fields
        payload[field.name] = field.value;
      }
    }
  });

  return payload;
}

Accessibility

The form block includes comprehensive accessibility features:

  • Semantic HTML: Proper <label>, <fieldset>, <legend> elements
  • Required Indicators: Visual asterisks added via CSS ::after
  • Help Text: Associated via aria-describedby
  • Error Handling: aria-invalid set on validation failure
  • Live Regions: Status messages announced with aria-live="polite"
  • Conditional Fields: aria-hidden, aria-controls, aria-controlledby
  • Focus Management: First invalid field focused and scrolled into view
  • Keyboard Navigation: Hidden fields excluded from tab order
  • Toggle Switches: role="switch" and aria-checked
WCAG 2.1 AA Compliant: Meets accessibility standards when used with proper field labels and help text.

Example: Contact Form Worker

Complete Cloudflare Worker that sends form data to Slack:

Full Worker Code
workers/contact_us/src/index.js 
export default {
  async fetch(request, env) {
    // Handle CORS preflight
    if (request.method === 'OPTIONS') {
      return new Response(null, {
        headers: {
          'Access-Control-Allow-Origin': '*',
          'Access-Control-Allow-Methods': 'POST, OPTIONS',
          'Access-Control-Allow-Headers': 'Content-Type',
        },
      });
    }

    if (request.method !== 'POST') {
      return new Response('Method not allowed', { status: 405 });
    }

    try {
      const body = await request.json();
      const { data } = body;

      // Format message for Slack
      const message = {
        text: 'New Form Submission',
        blocks: [
          {
            type: 'header',
            text: { type: 'plain_text', text: 'New Contact Form Submission' },
          },
          {
            type: 'section',
            fields: Object.entries(data).map(([key, value]) => ({
              type: 'mrkdwn',
              text: `*${key}:*\n${value}`,
            })),
          },
        ],
      };

      // Send to Slack webhook
      await fetch(env.SLACK_WEBHOOK_URL, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(message),
      });

      return new Response('Success', {
        status: 200,
        headers: {
          'Access-Control-Allow-Origin': '*',
        },
      });
    } catch (error) {
      console.error('Error processing form:', error);
      return new Response('Error', { status: 500 });
    }
  },
};
