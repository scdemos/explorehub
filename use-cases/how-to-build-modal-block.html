How to Build a Modal Block

Create accessible modal dialogs that intercept fragment links and display content in overlays

Block Dialog Accessibility Advanced

Overview

The Modal block creates an accessible dialog system that automatically intercepts links to fragments (e.g., /fragments/disclaimer) and displays them in a modal overlay instead of navigating. It handles fragment loading, focus management, keyboard navigation, and scroll locking.

Key Features:
  • Link Interception: Auto-detects fragment links, opens in modal instead of navigation
  • Fragment Loading: Dynamically fetches and decorates fragment content
  • Accessibility: ARIA attributes, focus restore on close, Escape key, click-outside-to-close (no full focus trap implemented)
  • Scroll Locking: Prevents body scroll when modal is open
  • Focus Management: Returns focus to trigger element on close
  • Dynamic Blocks: Supports tabs, embeds, and other blocks within modal content

Authoring Structure

Add a modal block anywhere on the page (typically in a hidden section or footer):

Modal
(empty - block just enables modal functionality)

Then, create fragment links anywhere on the page:

<a href="/fragments/disclaimer">View Disclaimer</a>
<a href="/fragments/privacy-policy">Privacy Policy</a>

Behavior: Clicking these links opens the fragment in a modal instead of navigating to a new page.

Implementation

JavaScript Logic

Create blocks/modal/modal.js:

import { loadFragment } from '../fragment/fragment.js';
import { loadCSS } from '../../scripts/aem.js';
import { createTag, getBlockContext } from '../../scripts/shared.js';
import dynamicBlocks from '../dynamic/index.js';

const FRAGMENT_PREFIX = '/fragments/';

function getFragmentPath(href = '') {
  try {
    const url = new URL(href, window.location.origin);
    if (!url.pathname.startsWith(FRAGMENT_PREFIX)) return null;
    return `${url.pathname}${url.search}`;
  } catch {
    return null;
  }
}

export function setupFragmentModal(el) {
  if (window.__fragmentModalReady) return;
  window.__fragmentModalReady = true;

  const { eventRoot } = getBlockContext(el);

  loadCSS(`${window.hlx.codeBasePath}/blocks/modal/modal.css`);

  const closeBtn = createTag('button', { type: 'button', class: 'modal-close', 'aria-label': 'Close dialog' }, '×');
  const content = createTag('div', { class: 'modal-content' });
  const dialog = createTag('div', {
    class: 'modal-dialog',
    role: 'dialog',
    'aria-modal': 'true',
    'aria-label': 'Dialog',
  }, [closeBtn, content]);
  const backdrop = createTag('div', { class: 'modal-backdrop', 'aria-hidden': 'true' });
  const modalRoot = createTag('div', { class: 'modal', hidden: 'true' }, [backdrop, dialog]);
  document.body.append(modalRoot);
  let previousOverflow = '';
  let previousFocus = null;

  const close = () => {
    modalRoot.hidden = true;
    content.replaceChildren();
    document.body.style.overflow = previousOverflow;
    if (previousFocus?.focus) previousFocus.focus();
  };

  const open = async (path) => {
    previousFocus = el.getRootNode().activeElement;
    modalRoot.hidden = false;
    previousOverflow = document.body.style.overflow;
    document.body.style.overflow = 'hidden';
    content.textContent = 'Loading...';
    closeBtn.focus();

    try {
      const fragment = await loadFragment(path);
      if (fragment) {
        const main = createTag('main', { class: 'modal-main' });
        main.append(...fragment.childNodes);
        content.replaceChildren(main);
        await dynamicBlocks(main);
      } else {
        content.textContent = 'Unable to load this content right now.';
      }
      dialog.scrollTop = 0;
    } catch {
      content.textContent = 'Unable to load this content right now.';
    }
  };

  closeBtn.addEventListener('click', close);
  backdrop.addEventListener('click', close);
  eventRoot.addEventListener('keydown', (e) => {
    if (e.key === 'Escape' && !modalRoot.hidden) close();
  });

  eventRoot.addEventListener('click', (e) => {
    const link = e.target.closest('main a[href*="/fragments/"]');
    if (!link) return;
    if (link.closest('header, footer, nav, .modal')) return;
    if (e.metaKey || e.ctrlKey || e.shiftKey || e.altKey) return;
    if (link.target === '_blank') return;
    const path = getFragmentPath(link.href);
    if (!path) return;
    e.preventDefault();
    open(path);
  });
}

export default function decorate(block) {
  setupFragmentModal(block);
  block.style.display = 'none';
}

    Modal->>Modal: Insert into dialog

    Modal->>Modal: Clear content
    Modal->>Modal: Restore previousFocus
    Modal->>User: Modal hidden

Key Mechanisms

1. Link Interception

eventRoot.addEventListener('click', (e) => {
  const link = e.target.closest('main a[href*="/fragments/"]');
  if (!link) return;
  if (link.closest('header, footer, nav, .modal')) return; // Exclusions
  if (e.metaKey || e.ctrlKey || e.shiftKey || e.altKey) return; // Modifiers
  if (link.target === '_blank') return; // New window
  const path = getFragmentPath(link.href);
  if (!path) return;
  e.preventDefault();
  open(path);
});

Filtering:

  • Only intercepts links in <main> (not header/footer/nav)
  • Respects modifier keys (Ctrl+Click = new tab still works)
  • Ignores target="_blank" links
  • Validates URL starts with /fragments/

2. Focus Management

const open = async (path) => {
  previousFocus = el.getRootNode().activeElement; // Save current focus
  modalRoot.hidden = false;
  closeBtn.focus(); // Move focus to close button
  // ... load content
};

const close = () => {
  modalRoot.hidden = true;
  if (previousFocus?.focus) previousFocus.focus(); // Restore focus
};

Ensures keyboard users return to the element they were on before opening modal.

3. Scroll Locking

const open = async (path) => {
  previousOverflow = document.body.style.overflow;
  document.body.style.overflow = 'hidden'; // Lock scroll
};

const close = () => {
  document.body.style.overflow = previousOverflow; // Restore scroll
};

Prevents background page from scrolling while modal is open.

4. Singleton Pattern

export function setupFragmentModal(el) {
  if (window.__fragmentModalReady) return;
  window.__fragmentModalReady = true;
  // ... setup code
}

Ensures modal UI is only created once, even if multiple modal blocks exist.

Common Use Cases

1. Legal Disclaimers

<p>See our <a href="/fragments/disclaimer">investment disclaimer</a> for details.</p>

Result: Disclaimer opens in modal, user doesn't leave page

2. Terms & Conditions

<p>By signing up, you agree to our <a href="/fragments/terms">Terms of Service</a>.</p>

Result: Terms open in scrollable modal dialog

3. Help Content

<button><a href="/fragments/how-it-works">How does this work?</a></button>

Result: Contextual help opens in modal

4. Quick Reference

<p>Check the <a href="/fragments/glossary">glossary</a> for definitions.</p>

Result: Glossary fragment loads in modal for quick lookup

4. Nested Modals

// Track modal stack
const modalStack = [];

const open = async (path) => {
  modalStack.push({ path, previousFocus, previousOverflow });
  // ... existing logic
};

const close = () => {
  const state = modalStack.pop();
  if (!state) return;
  // ... existing logic

  // If there's a previous modal, show it
  if (modalStack.length > 0) {
    const prevState = modalStack[modalStack.length - 1];
    loadFragment(prevState.path);
  }
};

Best Practices

Content

  • Keep focused: Modal content should be concise and focused on single topic
  • Avoid deep nesting: Don't open modals from within modals
  • Clear close affordances: Multiple ways to close (×, backdrop, Escape)
  • Loading feedback: Show loading state for slow fragments

Accessibility

  • ARIA attributes: role="dialog", aria-modal="true", aria-label
  • Focus trap: Consider trapping focus within modal (advanced)
  • Keyboard navigation: Close button must be keyboard accessible
  • Screen readers: Announce modal open/close events

Performance

  • Lazy load CSS: Load modal styles only when first modal opens
  • Clear content on close: Prevent memory leaks from lingering DOM
  • Cache fragments: Consider caching frequently-opened fragments
