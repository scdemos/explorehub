Overview

Full-featured search block that fetches content from query-index, filters by keywords, displays results as cards or list, and provides sidebar filters for faceted search.

Configuration Options

Key Values Description
view cards | list Display layout (default: cards)
keywords Comma-separated Include only content with these keywords
excluded-keywords Comma-separated Exclude content with these keywords
searchbar enabled Show search input field
* (custom) Comma-separated Creates a filter group in sidebar

2. Fetching Data from Query Index

The block fetches content metadata from /query-index.json in batches (500 items per request):

Recursive batch fetching (search.js:94-108) 
async function fetchAllResults(keywords, excluded) {
  const allArticles = [];
  const limit = 500;
  let offset = 0;
  let hasMore = true;

  while (hasMore) {
    const articles = await fetchQueryIndexPage(offset, limit);
    allArticles.push(...articles);
    hasMore = articles.length === limit;
    offset += limit;
  }

  return matchArticles(allArticles, keywords, excluded);
}

3. Constructing the DOM

Results are rendered as cards or list items. Filter groups become sidebar checkboxes:

Building result cards (search.js:110-140) 
function buildResultItem(article, view) {
  const item = createTag('div', { class: `search-result ${view}` });

  const link = createTag('a', { href: article.path });
  const title = createTag('h3', {}, article.title);
  const description = createTag('p', {}, article.description);
  const date = createTag('time', {}, formatDate(article.date));

  link.append(title, description, date);
  item.append(link);

  return item;
}

Accessibility & Performance

Accessibility Features
  • Semantic HTML: <nav>, <form>, <article>
  • ARIA labels on filter checkboxes and search input
  • Keyboard navigation: Tab through filters, Enter to submit search
  • Focus management: Results announce "X results found"
  • Screen reader: Filter counts and active filters announced
Performance Optimizations
  • Lazy loading: Block decorates when in viewport
  • Batch fetching: Query-index fetched in 500-item chunks
  • Debounced search: 300ms delay on search input
  • CSS containment: contain: layout style on cards
  • Minimal reflows: DOM updates batched with DocumentFragment
