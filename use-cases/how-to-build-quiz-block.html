How to Build a Quiz Block

Complete implementation guide for interactive quizzes with immediate feedback, scoring, and slider navigation

Block Interactive Advanced

Overview

The Quiz block creates interactive knowledge assessments with immediate feedback. It supports radio (single answer) and checkbox (multiple answer) questions, slider navigation for multi-question quizzes, scoring, and custom completion messages. Perfect for educational content, training, and engagement.

View Live Demo AEM Boilerplate

Key Features

  • Question Types: Single answer (radio) or multiple answers (checkbox)
  • Slider Navigation: For multi-question quizzes with prev/next buttons
  • Progress Dots: Visual progress indicator
  • Immediate Feedback: Per-question feedback with snippets
  • Scoring: Automatic scoring with completion events
  • Custom Messages: Configurable completion messages
  • Validation: Ensures all questions answered before submission
  • Accessibility: ARIA attributes, keyboard navigation, screen reader support

Implementation

Step 1: Parse Quiz Structure

The quiz block parses the table structure to extract configuration and questions:

Parse Rows Code
quiz.js - parseRows (lines 11-60) 
function parseRows(block) {
  const rows = [...block.querySelectorAll(':scope > div')];

  // Default configuration
  const config = {
    completeMessage: 'Great job! You completed the quiz.',
    doNotMarkLessonAsCompleted: false,
  };

  // Find config rows (before "Questions" separator)
  let startIndex = 0;
  for (let i = 0; i < rows.length; i += 1) {
    const firstCol = normalizeText(rows[i].children[0]?.textContent);
    const secondCol = normalizeText(rows[i].children[1]?.textContent);

    if (firstCol.toLowerCase() === 'questions') {
      startIndex = i + 1; // Questions start after this row
      break;
    }

    // Parse config values
    if (firstCol.toLowerCase() === 'complete message') {
      config.completeMessage = secondCol || config.completeMessage;
    }
    if (firstCol.toLowerCase() === 'do not mark lesson as completed') {
      config.doNotMarkLessonAsCompleted = toBool(secondCol);
    }
  }

  // Parse questions from remaining rows
  const questions = [];
  let currentQuestion = null;

  rows.slice(startIndex).forEach((row) => {
    const questionCell = normalizeText(row.children[0]?.textContent);
    const optionText = normalizeText(row.children[1]?.textContent);
    const isCorrect = toBool(row.children[2]?.textContent);
    const snippet = normalizeText(row.children[3]?.textContent);

    // New question (Column 1 has text)
    if (questionCell) {
      currentQuestion = {
        text: questionCell,
        options: [],
      };
      questions.push(currentQuestion);
    }

    // Skip rows with no option text
    if (!currentQuestion || !optionText) return;

    // Add option to current question
    currentQuestion.options.push({
      text: optionText,
      correct: isCorrect,
      snippet,
    });
  });

  return { config, questions };
}

How it works:

  • Scans rows until finding "Questions" separator
  • Extracts config from rows before separator
  • Groups options by question (question text only in first row)
  • Automatically determines question type based on correct answer count

Step 2: Build Question Elements

Each question becomes a fieldset with radio buttons or checkboxes:

Question Building Code
quiz.js - Build questions (lines 104-136) 
questions.forEach((question, qIndex) => {
  // Determine correct answer indexes
  const correctIndexes = question.options
    .map((option, index) => (option.correct ? index : null))
    .filter((idx) => idx !== null);

  // Multiple correct answers = checkbox question
  const multiCorrect = correctIndexes.length > 1;

  // Create fieldset for semantic grouping
  const fieldset = createTag('fieldset', {
    class: 'quiz-question',
    'data-question-index': String(qIndex)
  });

  const legend = createTag('legend', { class: 'quiz-question-title' }, question.text);
  fieldset.append(legend);

  // Add instruction for checkbox questions
  if (multiCorrect) {
    fieldset.append(createTag('p', { class: 'quiz-instruction' }, 'Select all that apply.'));
  }

  // Build options container
  const options = createTag('div', { class: 'quiz-options' });

  question.options.forEach((option, oIndex) => {
    const inputId = `quiz-${qIndex}-${oIndex}`;

    // Create input (radio or checkbox)
    const input = createTag('input', {
      id: inputId,
      type: multiCorrect ? 'checkbox' : 'radio',
      name: `question-${qIndex}`,
      value: String(oIndex),
    });

    // Create label with input and text
    const label = createTag('label', { class: 'quiz-option', for: inputId }, [
      input,
      createTag('span', { class: 'quiz-option-label' }, option.text),
    ]);

    options.append(label);
  });

  // Add feedback slot (empty until submission)
  const feedbackSlot = createTag('div', { class: 'quiz-feedback-slot' });
  fieldset.append(options, feedbackSlot);

  // Store correct indexes as data attribute for submission check
  fieldset.dataset.correctIndexes = JSON.stringify(correctIndexes);

  sliderTrack.append(fieldset);
});

Step 3: Slider Navigation

For multi-question quizzes, a slider provides smooth navigation:

Slider Implementation Code
quiz.js - Slider navigation (lines 138-169) 
let currentIndex = 0;

// Create navigation buttons
const navPrev = createTag('button', {
  type: 'button',
  class: 'quiz-nav-btn quiz-nav-prev',
  'aria-label': 'Previous question',
}, '← Back');

const navNext = createTag('button', {
  type: 'button',
  class: 'quiz-nav-btn quiz-nav-next',
  'aria-label': 'Next question',
}, 'Next →');

// Create progress dots
const dots = questions.map((_, i) => createTag('li', {
  class: `quiz-nav-dot${i === 0 ? ' is-active' : ''}`,
  'aria-hidden': 'true',
}));
const navDots = createTag('ol', { class: 'quiz-nav-dots' }, dots);

// Check if current question is answered
function currentQuestionAnswered() {
  const currentQuestion = sliderTrack.querySelectorAll('.quiz-question')[currentIndex];
  return currentQuestion ? getSelectedIndexes(currentQuestion).length > 0 : false;
}

// Render slider state
function renderSlider() {
  // Slide to current question (CSS transform)
  sliderTrack.style.transform = `translateX(-${currentIndex * 100}%)`;

  // Update active dot
  dots.forEach((dot, i) => dot.classList.toggle('is-active', i === currentIndex));

  // Disable prev button on first question
  navPrev.disabled = currentIndex === 0;
  navPrev.classList.toggle('is-hidden', currentIndex === 0);

  // Hide next button on last question
  navNext.classList.toggle('is-hidden', currentIndex === questions.length - 1);

  // Disable next button if current question not answered
  navNext.disabled = !currentQuestionAnswered();

  // Show submit button only on last question
  submit.hidden = currentIndex !== questions.length - 1;
}

// Navigation event listeners
navPrev.addEventListener('click', () => {
  currentIndex = Math.max(0, currentIndex - 1);
  renderSlider();
});

navNext.addEventListener('click', () => {
  currentIndex = Math.min(questions.length - 1, currentIndex + 1);
  renderSlider();
});

// Enable next button when current question is answered
sliderTrack.addEventListener('change', () => {
  navNext.disabled = !currentQuestionAnswered();
});

// Initial render
renderSlider();

Slider Features:

  • CSS transform for smooth sliding animation
  • Progress dots show current position
  • Next button disabled until question answered
  • Submit button only appears on last question
  • Prev button hidden on first question

Step 4: Submission and Feedback

On submit, the quiz validates answers, shows feedback, and calculates score:

Submission Handler Code
quiz.js - Handle submit (lines 197-263) 
form.addEventListener('submit', (event) => {
  event.preventDefault();

  let score = 0;
  let allAnswered = true;
  const questionEls = [...form.querySelectorAll('.quiz-question')];

  questionEls.forEach((questionEl) => {
    // Get selected options
    const selected = getSelectedIndexes(questionEl);

    // Get correct answer indexes from data attribute
    const correctIndexes = JSON.parse(questionEl.dataset.correctIndexes || '[]');

    const feedbackSlot = questionEl.querySelector('.quiz-feedback-slot');
    const optionEls = [...questionEl.querySelectorAll('.quiz-option')];

    // Clear previous feedback
    feedbackSlot.textContent = '';
    optionEls.forEach((el) => el.classList.remove('is-selected', 'is-correct', 'is-wrong'));

    // Check if question was answered
    if (!selected.length) {
      allAnswered = false;
      feedbackSlot.append(
        buildFeedback(false, ['Please select an answer before submitting.'])
      );
      return;
    }

    // Check if answer is correct (all correct options selected, no wrong ones)
    const correct = isCorrectSelection(selected, correctIndexes);
    if (correct) score += 1;

    // Collect feedback snippets for selected options
    const snippets = [];
    selected.forEach((selectedIndex) => {
      const label = optionEls[selectedIndex];
      const isCorrectOption = correctIndexes.includes(selectedIndex);

      // Mark option as selected + correct/wrong
      label?.classList.add('is-selected', isCorrectOption ? 'is-correct' : 'is-wrong');

      // Add snippet if available
      const snippet = questions[Number(questionEl.dataset.questionIndex)]
        .options[selectedIndex]?.snippet;
      if (snippet) snippets.push(snippet);
    });

    // If no snippets and answer wrong, use first correct option's snippet
    if (!snippets.length && !correct) {
      const firstCorrect = correctIndexes[0];
      const fallback = questions[Number(questionEl.dataset.questionIndex)]
        .options[firstCorrect]?.snippet;
      if (fallback) snippets.push(fallback);
    }

    // Show feedback
    feedbackSlot.append(buildFeedback(correct, snippets));
  });

  // Handle unanswered questions
  if (!allAnswered) {
    if (isSlider) {
      // Jump to first unanswered question
      const firstUnanswered = questionEls.findIndex(
        (questionEl) => !getSelectedIndexes(questionEl).length
      );
      if (firstUnanswered >= 0) {
        currentIndex = firstUnanswered;
        renderSlider();
      }
    }
    status.textContent = 'Please answer all questions and try again.';
    return;
  }

  // Display results
  const total = questions.length;

  if (score === total) {
    // Perfect score
    completeBanner.textContent = config.completeMessage;
    completeBanner.className = 'quiz-complete-banner is-success';
    completeBanner.hidden = false;
    status.textContent = `${config.completeMessage} (${score}/${total})`;

    // Dispatch completion event (for LMS integration, etc.)
    if (!config.doNotMarkLessonAsCompleted) {
      window.dispatchEvent(new CustomEvent('quiz:completed', {
        detail: { score, total }
      }));
    }
  } else {
    // Incomplete - show retry message
    completeBanner.textContent = `You scored ${score} of ${total} — review each question and try again.`;
    completeBanner.className = 'quiz-complete-banner is-retry';
    completeBanner.hidden = false;
    status.textContent = `You got ${score}/${total}.`;
  }
});

Feedback Features:

  • Per-option visual feedback (green checkmark / red X)
  • Text snippets explain correct/incorrect answers
  • Automatic navigation to first unanswered question
  • Success banner for perfect score
  • Retry message for incomplete attempts
  • Custom event for LMS/tracking integration

Custom Events

The quiz dispatches a custom event on completion for LMS integration or tracking:

Listen for quiz completion 
// Listen for quiz completion
window.addEventListener('quiz:completed', (event) => {
  const { score, total } = event.detail;

  console.log(`Quiz completed: ${score}/${total}`);

  // Send to analytics
  dataLayer.push({
    event: 'quiz_completed',
    score: score,
    total: total,
    percentage: Math.round((score / total) * 100)
  });

  // Mark lesson complete in LMS
  if (window.LMS) {
    window.LMS.markLessonComplete();
  }
});
