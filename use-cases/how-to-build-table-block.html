How to Build a Table Block

Create accessible HTML tables with automatic header detection and alignment support

Block Data Display Accessibility Beginner

Overview

The Table block converts authored table content into semantic HTML tables with proper <thead>, <tbody>, <th>, and <td> elements. It supports optional headers, horizontal and vertical alignment, and responsive styling.

Key Features:
  • Semantic HTML: Proper table structure with thead/tbody/th/td
  • Header Support: First row becomes <thead> with <th scope="col">
  • No-Header Variant: table (no-header) treats all rows as data
  • Alignment: Supports data-align (left, center, right) and data-valign (top, middle, bottom)
  • Responsive: Horizontal scrolling on small screens

Implementation

JavaScript Logic

Create blocks/table/table.js:

function buildCell(rowIndex) {
  const cell = rowIndex ? document.createElement('td') : document.createElement('th');
  if (!rowIndex) cell.setAttribute('scope', 'col');
  return cell;
}

export default async function decorate(block) {
  const table = document.createElement('table');
  const thead = document.createElement('thead');
  const tbody = document.createElement('tbody');

  const header = !block.classList.contains('no-header');
  if (header) table.append(thead);
  table.append(tbody);

  [...block.children].forEach((child, i) => {
    const row = document.createElement('tr');
    if (header && i === 0) thead.append(row);
    else tbody.append(row);
    [...child.children].forEach((col) => {
      const cell = buildCell(header ? i : i + 1);
      const align = col.getAttribute('data-align');
      const valign = col.getAttribute('data-valign');
      if (align) cell.style.textAlign = align;
      if (valign) cell.style.verticalAlign = valign;
      cell.innerHTML = col.innerHTML;
      row.append(cell);
    });
  });
  block.innerHTML = '';
  block.append(table);
}

How It Works

Header Detection

const header = !block.classList.contains('no-header');
if (header) table.append(thead);

If variant is NOT no-header, first row becomes <thead>.

Cell Type

function buildCell(rowIndex) {
  const cell = rowIndex ? document.createElement('td') : document.createElement('th');
  if (!rowIndex) cell.setAttribute('scope', 'col');
  return cell;
}

Row 0 (if header enabled) creates <th> with scope="col" for accessibility.

Alignment

const align = col.getAttribute('data-align');
const valign = col.getAttribute('data-valign');
if (align) cell.style.textAlign = align;
if (valign) cell.style.verticalAlign = valign;

Reads data-align and data-valign attributes from authored cells and applies as inline styles.

2. Sortable Columns

export default async function decorate(block) {
  // ... existing table build code

  // Add sort functionality
  const headers = table.querySelectorAll('thead th');
  headers.forEach((header, index) => {
    header.style.cursor = 'pointer';
    header.addEventListener('click', () => sortTable(table, index));
  });
}

function sortTable(table, columnIndex) {
  const tbody = table.querySelector('tbody');
  const rows = [...tbody.querySelectorAll('tr')];

  rows.sort((a, b) => {
    const aText = a.children[columnIndex].textContent.trim();
    const bText = b.children[columnIndex].textContent.trim();
    return aText.localeCompare(bText, undefined, { numeric: true });
  });

  rows.forEach(row => tbody.appendChild(row));
}

Best Practices

Content

  • Concise headers: Keep column headers short and descriptive
  • Consistent data: Use same units/format within columns
  • Limit columns: Max 5-6 columns for readability on mobile
  • Use headers: Always include headers unless data is truly headerless

Accessibility

  • Scope attribute: Always set scope="col" on <th>
  • Caption: Consider adding <caption> for context
  • Color contrast: Ensure sufficient contrast for text and borders
  • Keyboard navigation: Ensure table is keyboard navigable

Responsive Design

  • Horizontal scroll: Enable for wide tables on mobile
  • Font size: Reduce slightly on small screens
  • Padding: Adjust cell padding for touch targets
  • Breakpoint: Consider card layout for very complex tables on mobile
