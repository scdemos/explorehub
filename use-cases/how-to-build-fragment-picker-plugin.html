How to Build a Fragment Picker DA Plugin

A two-panel tree + live preview that inserts a fragment link into the open DA document via the DA SDK.

DA Plugin DA SDK Tree Library

Overview

The fragment-picker is a self-contained plugin under tools/plugins/fragments/. Two files do the work:

  • fragments.html — the static shell (left tree panel + right preview panel + insert button)
  • fragments.js — DA SDK wiring, crawl over /fragments, tree rendering, preview iframe, insert handler
Sidekick / DA Library registration: the plugin is built but is not currently registered in tools/sidekick/config.json. Open tools/sidekick/config.json to confirm; only the experimentation plugin is wired up there. To use this plugin you need to either add a plugins[] entry pointing at /tools/plugins/fragments/fragments.html, or invoke it from a DA Library config that lists the same path.

Implementation

1. DA SDK + tree crawl

import DA_SDK from 'https://da.live/nx/utils/sdk.js';
import { crawl } from 'https://da.live/nx/public/utils/tree.js';

const FRAGMENTS_BASE = '/fragments';
const CONSTANTS = {
  AUTO_HIDE_DELAY: 1000,
  CRAWL_THROTTLE: 10,
  ICONS: {
    FOLDER: '/.da/icons/folder-icon.png',
    FOLDER_OPEN: '/.da/icons/folder-open-icon.png',
    FRAGMENT: '/.da/icons/fragment-icon.png',
  },
};

let selectedFragment = null;

(async function init() {
  try {
    const { actions, context } = await DA_SDK;
    // ... wire search, insert button, keyboard nav, then loadFragments()
  } catch (e) {
    showMessage('Initialization failed. Please refresh the page.', true);
  }
}());

2. Crawling /fragments

async function loadFragments() {
  const fragmentsContainer = document.querySelector('.fragments-list');
  const { context: loadContext, token } = await DA_SDK;
  const path = `/${loadContext.org}/${loadContext.repo}${FRAGMENTS_BASE}`;
  const basePath = `/${loadContext.org}/${loadContext.repo}`;

  const files = [];
  const { results } = crawl({
    path,
    callback: (file) => {
      if (file.path.endsWith('.html')) files.push(file);
    },
    throttle: CONSTANTS.CRAWL_THROTTLE,
    mode: 'horizontal',
    method: 'GET',
    headers: { Authorization: `Bearer ${token}` },
  });
  await results;

  fragmentsContainer.innerHTML = '';
  if (files.length === 0) {
    fragmentsContainer.innerHTML = '
No fragments found
';
    return;
  }
  const tree = createFileTree(files, basePath);
  // ...render tree...
}

3. Preview iframe URL

Selecting a tree item renders a preview to the AEM page URL derived from context.org/context.repo:

function showPreview(fragmentPath, fragmentName, context, fragmentElement) {
  const iframe = document.querySelector('.preview-iframe');
  const placeholder = document.querySelector('.preview-placeholder');
  const insertBtn = document.querySelector('.insert-btn');

  const basePath = `/${context.org}/${context.repo}`;
  const displayPath = fragmentPath.replace(basePath, '').replace(/\.html$/, '');
  const previewUrl = `https://main--${context.repo}--${context.org}.aem.page${displayPath}`;

  // Update selection visuals on the tree
  if (selectedFragment?.element) {
    selectedFragment.element.classList.remove('selected');
    selectedFragment.element.classList.add('was-selected');
  }
  selectedFragment = { path: fragmentPath, name: fragmentName, element: fragmentElement };
  fragmentElement.classList.remove('was-selected');
  fragmentElement.classList.add('selected');

  insertBtn.disabled = false;
  insertBtn.setAttribute('aria-label', `Insert fragment "${fragmentName}"`);
  iframe.src = previewUrl;
  iframe.classList.remove('hidden');
  placeholder.classList.add('hidden');
}

4. Inserting via DA SDK actions.sendHTML

function handleFragmentInsert(actions, context) {
  if (!selectedFragment) {
    showMessage('No fragment selected', true);
    return;
  }
  if (!actions?.sendHTML) {
    showMessage('Cannot insert fragment: Editor not available', true);
    return;
  }
  const basePath = `/${context.org}/${context.repo}`;
  const displayPath = selectedFragment.path.replace(basePath, '').replace(/\.html$/, '');
  const fragmentUrl = `https://main--${context.repo}--${context.org}.aem.page${displayPath}`;
  actions.sendHTML(`${fragmentUrl}`);
  showMessage('Fragment inserted successfully', false, true);
  actions.closeLibrary();
}

The HTML inserted is the same shape that blocks/fragment/fragment.js auto-blocks on at runtime. See the Fragment block guide for the rendering side.

5. Keyboard navigation

The .fragments-list listens for ArrowUp/ArrowDown across .fragment-btn-item nodes (also triggers preview), and Enter to invoke the Insert button:

fragmentsList.addEventListener('keydown', (e) => {
  const allFragments = Array.from(fragmentsList.querySelectorAll('.fragment-btn-item'));
  if (allFragments.length === 0) return;
  const currentIndex = allFragments.findIndex((btn) => btn === document.activeElement);
  if (e.key === 'ArrowDown') {
    e.preventDefault();
    const next = (currentIndex + 1) % allFragments.length;
    allFragments[next].focus(); allFragments[next].click();
  } else if (e.key === 'ArrowUp') {
    e.preventDefault();
    const prev = currentIndex <= 0 ? allFragments.length - 1 : currentIndex - 1;
    allFragments[prev].focus(); allFragments[prev].click();
  } else if (e.key === 'Enter' && currentIndex >= 0) {
    e.preventDefault();
    insertBtn.click();
  }
});

How It Works

sequenceDiagram
  participant User
  participant Plugin as fragments.html
  participant SDK as DA_SDK
  participant DA as DA Admin
  participant Doc as Author document

  User->>Plugin: Open library / plugin
  Plugin->>SDK: await DA_SDK
  SDK-->>Plugin: { actions, context, token }
  Plugin->>DA: crawl /fragments via Bearer token
  DA-->>Plugin: file list
  Plugin->>User: render tree
  User->>Plugin: click fragment
  Plugin->>Plugin: preview iframe → main--repo--org.aem.page/...
  User->>Plugin: click Insert
  Plugin->>SDK: actions.sendHTML(`<a href="..." class="fragment">...</a>`)
  Plugin->>SDK: actions.closeLibrary()
  SDK->>Doc: insert link into editor

Notes & Gotchas

  • The crawl uses token from DA_SDK as a Bearer header. The token is per-session — don't cache it across reloads.
  • The preview URL is always main--{repo}--{org}.aem.page. If your fragments aren't published to main, the preview iframe will 404.
  • Class names matter: the JS expects exactly .preview-iframe and .message-wrapper (not .preview-frame / .message-container).
  • Folder icons are loaded from /.da/icons/folder-icon.png and /.da/icons/folder-open-icon.png — if your project doesn't host these, swap to inline SVG.
  • DA Library v2 supports a plugins array in the library config; you can also expose this from tools/sidekick/config.json by adding an entry that points at /tools/plugins/fragments/fragments.html.

Customization Ideas

  • Different base path — change FRAGMENTS_BASE to point at /library/components, /snippets, etc.
  • Insert as block — instead of a fragment <a>, send a full block table (e.g. an embed block) by replacing actions.sendHTML(...) with serialized table HTML.
  • Filter by folder — accept a ?folder=... query parameter and scope the crawl path.
  • Recently used — persist the last N inserted fragment paths in localStorage and render them as a top-of-tree group.
