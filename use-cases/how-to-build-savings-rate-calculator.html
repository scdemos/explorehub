How to Build a Savings Rate Calculator Block

Interactive calculator measuring the percentage of income saved for financial independence planning

Block Interactive Advanced

Overview

The Savings Rate Calculator helps users understand what percentage of their income they're saving and how that impacts their path to financial independence. It calculates savings rate from income, spending, and contributions, with optional Chart.js visualization showing the relationship between savings rate and years to financial independence.

Key Features:

  • Real-time savings rate calculation
  • Multiple input modes: total spending or category breakdown (housing, food, transportation, etc.)
  • Accounts for various income sources (salary, rental, investment, business)
  • Tracks retirement contributions (RRSP, TFSA, employer match)
  • Years-to-financial-independence estimation
  • Optional Chart.js visualization (savings rate vs. years to FI)
  • Color-coded savings rate assessment (poor, good, excellent)
  • Responsive layout with sidebar form
  • CAD currency and percentage formatting

How It Works

The calculator follows this workflow:

graph TD A[User Inputs Income & Spending] --> B[Calculate Total Income] B --> C[Calculate Total Spending] C --> D[Calculate Savings Amount] D --> E[Savings Rate = Savings / Income × 100] E --> F{Include Chart?} F -->|Yes| G[Load Chart.js] G --> H[Plot Savings Rate Curve] F -->|No| I[Display Metrics Only] H --> J[Estimate Years to FI] I --> J J --> K[Color-Code Assessment]

Calculation Logic:

  1. Total Income: Sum of salary, rental income, investment income, business income, and other
  2. Total Spending: Sum of all expense categories (or direct total if not using categories)
  3. Savings Amount: Total Income - Total Spending
  4. Savings Rate: (Savings Amount / Total Income) × 100
  5. Years to Financial Independence: Based on savings rate using standard FIRE calculations (4% rule)

Years to FI Formula:

The calculator uses the formula: yearsToFI = log(1 + (savingsRate / (1 - savingsRate)) × (1 / withdrawalRate)) / log(1 + investmentReturn)

This estimates how many years of saving at the current rate would lead to financial independence, assuming a 7% investment return and 4% safe withdrawal rate.

import { createTag, loadChartJs, createChart } from '../../scripts/shared.js';

const DEFAULTS = {
  monthlyAfterTaxIncome: 7000,
  monthlyRentalIncome: 0,
  monthlyInvestmentIncome: 0,
  monthlyBusinessIncome: 0,
  monthlyOtherIncome: 0,
  monthlySpending: 4200,
  useDetailedSpending: false,
  showChart: true,
};

function money(value) {
  return new Intl.NumberFormat('en-CA', {
    style: 'currency',
    currency: 'CAD',
    maximumFractionDigits: 0,
  }).format(value || 0);
}

function percent(value, digits = 1) {
  return \`\${(value || 0).toFixed(digits)}%\`;
}

function calculate(values) {
  const afterTaxIncome = Math.max(0, toNumber(values.monthlyAfterTaxIncome, DEFAULTS.monthlyAfterTaxIncome));
  const rentalIncome = Math.max(0, toNumber(values.monthlyRentalIncome, DEFAULTS.monthlyRentalIncome));
  const investmentIncome = Math.max(0, toNumber(values.monthlyInvestmentIncome, DEFAULTS.monthlyInvestmentIncome));
  const businessIncome = Math.max(0, toNumber(values.monthlyBusinessIncome, DEFAULTS.monthlyBusinessIncome));
  const otherIncome = Math.max(0, toNumber(values.monthlyOtherIncome, DEFAULTS.monthlyOtherIncome));

  const totalMonthlyIncome = afterTaxIncome + rentalIncome + investmentIncome + businessIncome + otherIncome;
  const totalMonthlySpending = Math.max(0, toNumber(values.monthlySpending, DEFAULTS.monthlySpending));

  const monthlySavings = totalMonthlyIncome - totalMonthlySpending;
  const savingsRate = totalMonthlyIncome > 0 ? (monthlySavings / totalMonthlyIncome) * 100 : 0;

  // Years to FI calculation (simplified)
  const investmentReturn = 0.07; // 7% annual return
  const withdrawalRate = 0.04; // 4% safe withdrawal rate
  const yearsToFI = savingsRate > 0
    ? Math.log(1 + (savingsRate / 100 / (1 - savingsRate / 100)) * (1 / withdrawalRate)) / Math.log(1 + investmentReturn)
    : Infinity;

  let assessment = 'Poor';
  if (savingsRate >= 50) assessment = 'Excellent';
  else if (savingsRate >= 20) assessment = 'Good';
  else if (savingsRate >= 10) assessment = 'Fair';

  return {
    totalMonthlyIncome,
    totalMonthlySpending,
    monthlySavings,
    savingsRate,
    yearsToFI: isFinite(yearsToFI) ? yearsToFI : null,
    assessment,
  };
}

function buildChartData() {
  const data = [];
  for (let rate = 5; rate <= 75; rate += 5) {
    const investmentReturn = 0.07;
    const withdrawalRate = 0.04;
    const years = Math.log(1 + (rate / 100 / (1 - rate / 100)) * (1 / withdrawalRate)) / Math.log(1 + investmentReturn);
    data.push({ savingsRate: rate, yearsToFI: years });
  }
  return data;
}

function drawChartWithChartJs(canvas) {
  if (!canvas) return undefined;
  const chartData = buildChartData();
  const labels = chartData.map((d) => \`\${d.savingsRate}%\`);
  const yearsData = chartData.map((d) => d.yearsToFI);

  const config = {
    type: 'line',
    data: {
      labels,
      datasets: [{
        label: 'Years to Financial Independence',
        data: yearsData,
        backgroundColor: 'rgba(57, 96, 119, 0.2)',
        borderColor: 'rgb(57, 96, 119)',
        borderWidth: 2,
        fill: true,
        tension: 0.3,
      }],
    },
    options: {
      responsive: true,
      maintainAspectRatio: true,
      aspectRatio: 2.3,
      plugins: {
        legend: { display: false },
        tooltip: {
          callbacks: {
            label(ctx) {
              return \`\${ctx.raw.toFixed(1)} years to FI\`;
            },
          },
        },
      },
      scales: {
        x: { title: { display: true, text: 'Savings Rate (%)' } },
        y: {
          title: { display: true, text: 'Years to FI' },
          beginAtZero: true,
          reverse: true,
        },
      },
    },
  };
  return createChart(canvas, config);
}

Financial Independence (FIRE) Context

The savings rate is the most important metric in the Financial Independence / Retire Early (FIRE) movement. This calculator helps users understand:

  • Higher savings rate = Faster path to FI: A 50% savings rate means FI in ~17 years, while 70% achieves FI in ~8.5 years
  • Non-linear relationship: Small increases in savings rate dramatically reduce years to FI
  • Income vs. Spending: Highlights that reducing spending has double benefit (more to save + lower FI target)
  • Safe Withdrawal Rate: Assumes 4% rule (can withdraw 4% of portfolio annually in retirement)

Savings Rate Benchmarks:

  • <10%: Poor (typical consumer, will work full career)
  • 10-20%: Fair (traditional retirement planning)
  • 20-50%: Good (accelerated path to FI)
  • 50%+: Excellent (FIRE achievable in 10-17 years)
  • 70%+: Exceptional (FI in under 10 years)

Chart.js Visualization

The optional chart shows the relationship between savings rate and years to financial independence. Key insights:

  • Steep curve at low rates: Going from 10% to 20% saves ~15 years
  • Diminishing returns at high rates: Going from 60% to 70% saves ~4 years
  • Visual motivation: Users see immediate impact of increasing savings
  • Lazy-loaded: Chart.js loaded asynchronously to avoid blocking page render

Accessibility Features

  • ARIA Live Region: Output announces results to screen readers
  • Semantic HTML: Proper form, label, and input elements
  • Keyboard Navigation: Full keyboard support for all inputs
  • Toggle for Detailed View: Checkbox to expand spending categories
  • Color-Coded Assessment: Visual + text indicators for savings rate quality
  • Canvas Label: Chart has aria-label describing content

Best Practices

  • Real-Time Feedback: Update savings rate on every input change
  • Multiple Income Sources: Account for side income, rentals, dividends
  • Optional Detail: Let users choose simple (total spending) or detailed (category breakdown)
  • Visual Feedback: Color-code assessment (red/yellow/green)
  • Educational Content: Explain what savings rate means and why it matters
  • Chart Toggle: Let users hide chart if they prefer numbers only
  • Mobile-First: Stacked layout on mobile, sidebar on desktop
  • Currency Formatting: Use Intl.NumberFormat for locale-aware display
