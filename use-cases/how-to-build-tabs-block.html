How to Build a Tabs Block

Section-metadata-driven tabs: each section becomes a tab panel, no nested authoring required

Block Navigation Section Metadata Dynamic Block

Overview

The tabs block in scdemos/demo is section-level, not block-level. Authors mark a sequence of sections with the same data-tab-id/data-tab-title metadata; a single empty tabs block placed at the start of the run collapses those sibling sections into one tabs UI at runtime.

Where it diverges from the Block Collection tabs:
  • Authoring is at the section level — there is no inner table per tab.
  • Decoration walks sibling sections from the block's parent until it finds a non-tab section.
  • The block also exposes createTabs(main), used by blocks/dynamic/index.js for runtime injection on any page that has tab sections.

From Authoring to Rendering

Step 1 — Plain HTML the document service emits

AEM converts each section's metadata into data-tab-id / data-tab-title attributes on the section div:

<div class="section" data-tab-id="overview" data-tab-title="Overview">
  <div class="default-content-wrapper">
    <div class="tabs"><div><div></div></div></div>
    <p>Overview content...</p>
  </div>
</div>
<div class="section" data-tab-id="features" data-tab-title="Features">
  <div class="default-content-wrapper"><p>Features content...</p></div>
</div>
<div class="section" data-tab-id="pricing" data-tab-title="Pricing">
  <div class="default-content-wrapper"><p>Pricing content...</p></div>
</div>

Note: only the first tab section contains a tabs block. The other sections are plain content.

Step 2 — JavaScript collects siblings and rebuilds

The block's decorate() climbs to .section, then walks nextElementSibling while sections still have data-tab-id:

function collectTabSections(currSection) {
  const tabDefs = [];
  let next = currSection.nextElementSibling;
  while (next?.classList.contains('section')) {
    const tabDef = getTabDefinition(next, tabDefs.length);
    if (!tabDef) break;          // first non-tab section ends the run
    tabDefs.push(tabDef);
    next = next.nextElementSibling;
  }
  return tabDefs;
}

Step 3 — Final DOM

Each sibling section is moved into a panel under a single tabs wrapper:

<div class="section tabs">
  <div class="tabs-wrapper">
    <div class="tabs-list" role="tablist" aria-orientation="horizontal">
      <button class="tabs-tab is-active"
              role="tab" aria-selected="true"
              aria-controls="desktop-panel-overview">Overview</button>
      <button class="tabs-tab"
              role="tab" aria-selected="false"
              aria-controls="desktop-panel-features">Features</button>
      <button class="tabs-tab"
              role="tab" aria-selected="false"
              aria-controls="desktop-panel-pricing">Pricing</button>
    </div>
    <div class="tabs-content">
      <div class="tab" role="tabpanel" aria-hidden="false">…overview section…</div>
      <div class="tab" role="tabpanel" aria-hidden="true">…features section…</div>
      <div class="tab" role="tabpanel" aria-hidden="true">…pricing section…</div>
    </div>
  </div>
</div>

Inactive panels are hidden by CSS using aria-hidden="true" (not the HTML hidden attribute).

Implementation

JavaScript — blocks/tabs/tabs.js (full source)

import { toClassName, loadCSS } from '../../scripts/aem.js';

let tabsStyleLoaded;

function getTabDefinition(section, fallbackIdx = 0) {
  const tabId = String(section.dataset?.tabId || '').trim();
  if (!tabId) return null;
  const title = String(section.dataset?.tabTitle || tabId).trim() || `Tab ${fallbackIdx + 1}`;
  return {
    id: toClassName(tabId) || `tab-${fallbackIdx + 1}`,
    title,
    section,
  };
}

function collectTabSections(currSection) {
  const tabDefs = [];
  let next = currSection.nextElementSibling;
  while (next?.classList.contains('section')) {
    const tabDef = getTabDefinition(next, tabDefs.length);
    if (!tabDef) break;
    tabDefs.push(tabDef);
    next = next.nextElementSibling;
  }
  return tabDefs;
}

function findTabGroups(main) {
  const sections = [...main.querySelectorAll('.section[data-tab-id]')]
    .filter((s) => !s.closest('.tabs-wrapper'));
  return sections.length ? [sections] : [];
}

function updateTabState(tabDefs, selectedId, tabButtons, tabPanels) {
  tabDefs.forEach((tabDef) => {
    const isSelected = tabDef.id === selectedId;
    const button = tabButtons[tabDef.id];
    const panel = tabPanels[tabDef.id];
    if (button) {
      button.setAttribute('aria-selected', isSelected ? 'true' : 'false');
      button.classList.toggle('is-active', isSelected);
    }
    if (panel) {
      panel.setAttribute('aria-hidden', isSelected ? 'false' : 'true');
    }
  });
}

function scrollActiveTab(button, tabList) {
  const listRect = tabList.getBoundingClientRect();
  const btnRect = button.getBoundingClientRect();
  const btnStart = btnRect.left - listRect.left + tabList.scrollLeft;
  const offset = btnStart - (tabList.clientWidth - button.offsetWidth) / 2;
  tabList.scrollLeft = Math.max(0, offset);
}

function buildTabsUI(tabDefs, tabsContainer, sectionId = '') {
  const hash = window.location.hash.replace('#', '').toLowerCase();
  const selectedId = tabDefs.find((tabDef) => tabDef.id === hash)?.id || tabDefs[0]?.id;

  const tabsWrapper = document.createElement('div');
  tabsWrapper.className = 'tabs-wrapper';

  const tabList = document.createElement('div');
  tabList.className = 'tabs-list';
  tabList.setAttribute('role', 'tablist');
  tabList.setAttribute('aria-orientation', 'horizontal');

  const tabContent = document.createElement('div');
  tabContent.className = 'tabs-content';

  const tabButtons = {};
  const tabPanels = {};

  tabDefs.forEach((tabDef) => {
    const baseId = `${tabDef.id}${sectionId ? `-${sectionId}` : ''}`;
    const buttonId = `desktop-${baseId}`;
    const panelId = `desktop-panel-${baseId}`;
    const isSelected = tabDef.id === selectedId;

    const button = document.createElement('button');
    button.className = 'tabs-tab';
    button.id = buttonId;
    button.type = 'button';
    button.role = 'tab';
    button.setAttribute('aria-controls', panelId);
    button.setAttribute('aria-selected', isSelected ? 'true' : 'false');
    button.classList.toggle('is-active', isSelected);
    button.textContent = tabDef.title;

    const panel = document.createElement('div');
    panel.className = 'tab';
    panel.id = panelId;
    panel.role = 'tabpanel';
    panel.setAttribute('aria-labelledby', buttonId);
    panel.setAttribute('aria-hidden', isSelected ? 'false' : 'true');
    panel.append(tabDef.section);

    button.addEventListener('click', () => {
      updateTabState(tabDefs, tabDef.id, tabButtons, tabPanels);
      scrollActiveTab(button, tabList);
      window.history.pushState({}, '', `${window.location.pathname}#${tabDef.id}`);
    });

    tabButtons[tabDef.id] = button;
    tabPanels[tabDef.id] = panel;
    tabList.append(button);
    tabContent.append(panel);
  });

  tabsWrapper.append(tabList, tabContent);
  const activeButton = tabButtons[selectedId];
  if (activeButton) {
    requestAnimationFrame(() => scrollActiveTab(activeButton, tabList));
  }
  return tabsWrapper;
}

export default function decorate(block) {
  const currSection = block.closest('.section');
  if (!currSection) return;
  const tabDefs = collectTabSections(currSection);
  if (!tabDefs.length) return;
  currSection.classList.add('tabs');
  tabDefs.forEach((def) => def.section.classList.remove('tabs'));
  const tabsUI = buildTabsUI(tabDefs, currSection, currSection.id || '');
  block.replaceChildren(tabsUI);
}

export async function createTabs(main) {
  if (!main) return;
  if (!tabsStyleLoaded) {
    tabsStyleLoaded = loadCSS(`${window.hlx.codeBasePath}/blocks/tabs/tabs.css`);
  }
  await tabsStyleLoaded;
  const tabGroups = findTabGroups(main);
  tabGroups.forEach((group) => buildTabsFromSections(group));
}

function buildTabsFromSections(tabSections) {
  if (!tabSections.length) return;
  const first = tabSections[0];
  const parent = first.parentNode;
  if (!parent) return;
  const tabDefs = tabSections
    .map((section, index) => getTabDefinition(section, index))
    .filter(Boolean);
  if (!tabDefs.length) return;
  tabDefs.forEach((def) => def.section.classList.remove('tabs'));
  const tabsContainer = document.createElement('div');
  tabsContainer.className = 'section tabs';
  parent.insertBefore(tabsContainer, first);
  const tabsUI = buildTabsUI(tabDefs, tabsContainer, first.id || '');
  tabsContainer.append(tabsUI);
}

Two entry points

  • decorate(block) — runs when the author placed an explicit empty tabs block in the first tab section.
  • createTabs(main) — exported helper. Loaded by blocks/dynamic/index.js in loadEager; converts any orphan run of .section[data-tab-id] into tabs even without an authored block.

State updates

  • Active panel is shown via aria-hidden="false" + a CSS rule. Inactive panels keep aria-hidden="true" and are hidden by CSS.
  • Click handlers run history.pushState with the tab id. There is no popstate listener — back/forward does not change the active tab.
  • On initial load the matching hash (if any) selects that tab and requestAnimationFrame centers it in the scroll list.

Customization Ideas

  • Arrow-key navigation — the demo source does not implement it; if needed, listen for ArrowLeft/ArrowRight on .tabs-list and call the existing updateTabState + scrollActiveTab.
  • Browser back/forward sync — add a window.addEventListener('popstate', ...) handler that re-runs updateTabState from location.hash.
  • Tab icons — read an extra data-tab-icon from the section metadata and prepend an <span class="icon icon-..."> to the button.
  • Vertical orientation — add a .tabs.vertical variant and rotate the flex direction; remove the viewport breakout.

Notes & Gotchas

  • Tabs are a section-level pattern. Authors do not nest content inside a single block table.
  • Inactive panels are still in the DOM — they are visually hidden but assistive tech can reach them. Use aria-hidden rather than hidden to allow CSS transitions if you add them.
  • createTabs(main) is also called by blocks/dynamic/index.js, so a plain page with sibling tab sections gets tabbed even with no authored block.
  • The CSS uses margin-inline: calc(50% - 50vw) to break out of the constrained section width. Beware of horizontal-overflow on the parent container.
  • UE: ue/models/blocks/tabs.json models the empty block; section-level metadata is configured via section.json (Style/Tab Id/Tab title fields).
