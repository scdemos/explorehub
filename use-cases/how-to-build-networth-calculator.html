How to Build a Net Worth Calculator Block

Interactive financial health calculator tracking assets, liabilities, and emergency fund readiness

Block Interactive Advanced

Overview

The Net Worth Calculator is a comprehensive financial planning tool that helps users calculate their net worth by tracking assets and liabilities. It also calculates emergency fund readiness and provides actionable insights on financial health.

Key Features:

  • Real-time calculation as users input values
  • Comprehensive asset tracking (cash, TFSA, RRSP, FHSA, home, vehicle, business, pension)
  • Liability tracking (mortgage, credit card, loans, tax owing)
  • Emergency fund calculation and readiness status
  • Optional home value inclusion in net worth
  • Configurable emergency fund target (3-12 months of expenses)
  • Visual metrics with color-coded status indicators
  • Responsive layout with sidebar form and results panel
  • CAD currency formatting

How It Works

The calculator follows this workflow:

graph TD A[User Inputs Values] --> B[Calculate Total Assets] B --> C[Calculate Total Liabilities] C --> D[Net Worth = Assets - Liabilities] D --> E{Include Home?} E -->|No| F[Adjust Net Worth Excluding Home] E -->|Yes| G[Keep Full Net Worth] F --> H[Calculate Emergency Fund Needed] G --> H H --> I[Compare Cash to Emergency Fund Target] I --> J[Display Results & Status] J --> K[Show Color-Coded Metrics]

Calculation Logic:

  1. Total Assets: Sum of cash, investments (TFSA, RRSP, FHSA, non-registered), home, pension, business, vehicle, and other assets
  2. Total Liabilities: Sum of mortgage, credit cards, line of credit, student loan, car loan, tax owing, and other liabilities
  3. Net Worth: Total Assets - Total Liabilities
  4. Emergency Fund Target: (Essential Monthly Expenses + Monthly Debt Payments) × Target Months
  5. Emergency Fund Status: Compare cash on hand to target, with color-coded visual feedback

function money(value) {
  return new Intl.NumberFormat('en-CA', {
    style: 'currency',
    currency: 'CAD',
    maximumFractionDigits: 0,
  }).format(value || 0);
}

function calculate(values) {
  const cash = Math.max(0, toNumber(values.cash, DEFAULTS.cash));
  const tfsa = Math.max(0, toNumber(values.tfsa, DEFAULTS.tfsa));
  const rrsp = Math.max(0, toNumber(values.rrsp, DEFAULTS.rrsp));
  const fhsa = Math.max(0, toNumber(values.fhsa, DEFAULTS.fhsa));
  const nonRegistered = Math.max(0, toNumber(values.nonRegistered, DEFAULTS.nonRegistered));
  const homeValue = Math.max(0, toNumber(values.homeValue, DEFAULTS.homeValue));
  const pensionValue = Math.max(0, toNumber(values.pensionValue, DEFAULTS.pensionValue));
  const businessValue = Math.max(0, toNumber(values.businessValue, DEFAULTS.businessValue));
  const vehicleValue = Math.max(0, toNumber(values.vehicleValue, DEFAULTS.vehicleValue));
  const otherAssets = Math.max(0, toNumber(values.otherAssets, DEFAULTS.otherAssets));

  const mortgage = Math.max(0, toNumber(values.mortgage, DEFAULTS.mortgage));
  const creditCard = Math.max(0, toNumber(values.creditCard, DEFAULTS.creditCard));
  const lineOfCredit = Math.max(0, toNumber(values.lineOfCredit, DEFAULTS.lineOfCredit));
  const studentLoan = Math.max(0, toNumber(values.studentLoan, DEFAULTS.studentLoan));
  const carLoan = Math.max(0, toNumber(values.carLoan, DEFAULTS.carLoan));
  const taxOwing = Math.max(0, toNumber(values.taxOwing, DEFAULTS.taxOwing));
  const otherLiabilities = Math.max(0, toNumber(values.otherLiabilities, DEFAULTS.otherLiabilities));

  const essentialExpenses = Math.max(0, toNumber(values.monthlyEssentialExpenses, DEFAULTS.monthlyEssentialExpenses));
  const debtPayments = Math.max(0, toNumber(values.monthlyDebtPayments, DEFAULTS.monthlyDebtPayments));
  const emergencyMonths = Math.max(3, Math.min(12, toNumber(values.targetEmergencyMonths, DEFAULTS.targetEmergencyMonths)));

  const totalAssets = cash + tfsa + rrsp + fhsa + nonRegistered + homeValue
    + pensionValue + businessValue + vehicleValue + otherAssets;
  const totalLiabilities = mortgage + creditCard + lineOfCredit + studentLoan
    + carLoan + taxOwing + otherLiabilities;

  const includeHome = Boolean(values.includeHomeInNetWorth);
  const netWorth = includeHome ? totalAssets - totalLiabilities
    : totalAssets - homeValue - totalLiabilities;

  const emergencyFundTarget = (essentialExpenses + debtPayments) * emergencyMonths;
  const emergencyFundStatus = cash >= emergencyFundTarget ? 'Ready' : 'Needs Attention';

  return {
    totalAssets,
    totalLiabilities,
    netWorth,
    emergencyFundTarget,
    emergencyFundStatus,
    cashOnHand: cash,
  };
}

Financial Planning Features

Emergency Fund Guidance:

  • Calculates recommended emergency fund based on essential expenses and debt payments
  • Adjustable target from 3-12 months of expenses
  • Color-coded status (green = ready, yellow/red = needs attention)

Asset Categories:

  • Liquid Assets: Cash on hand for immediate access
  • Tax-Advantaged Investments: TFSA, RRSP, FHSA (Canadian accounts)
  • Non-Registered Investments: Taxable investment accounts
  • Property & Other: Home, vehicle, business, pension values

Liability Tracking:

  • Mortgage debt
  • Consumer debt (credit cards, line of credit)
  • Installment loans (student, auto)
  • Tax obligations and other liabilities

Accessibility Features

  • ARIA Live Region: Output announces results to screen readers
  • Semantic HTML: Proper form, label, and input elements
  • Keyboard Navigation: Full keyboard support for all inputs
  • Tooltips: Contextual help for complex fields
  • Range Sliders: Accessible slider for emergency fund target months
  • Toggle Controls: Checkbox for including home in net worth calculation

Best Practices

  • Real-Time Feedback: Update calculations on every input change
  • Sensible Defaults: Pre-populate with realistic example values
  • Currency Formatting: Use Intl.NumberFormat for locale-aware display
  • Validation: Constrain inputs to positive values using Math.max(0, value)
  • Grouped Inputs: Organize fields by category (emergency, assets, liabilities)
  • Visual Hierarchy: Use headings and borders to separate sections
  • Color-Coded Status: Green for healthy, yellow/red for needs attention
  • Responsive Design: Mobile-first with sidebar on desktop
