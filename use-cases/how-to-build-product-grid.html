How to Build a Product Grid Block

Dynamic product catalog powered by JSON index

Block E-Commerce Intermediate

Overview

The Product Grid block displays a responsive grid of product cards fetched from a product index JSON file. It's designed for e-commerce use cases where product data is managed centrally and rendered dynamically across multiple pages.

Key Features

  • JSON-powered - Loads products from external index files
  • Responsive grid - 1 column mobile, 2 tablet, 3 desktop
  • Optimized images - Uses AEM's picture element with multiple breakpoints
  • Relative path resolution - Handles relative image paths automatically
  • Price formatting - Canadian dollar formatting with CA$ prefix
  • Loading states - Visual feedback during data fetch
  • Error handling - Graceful fallback for failed requests

Building Blocks

1. Core Components

  • Index Fetcher - Retrieves product data from JSON endpoint
  • Image Resolver - Converts relative paths to absolute URLs
  • Card Builder - Creates individual product card elements
  • Picture Generator - Leverages AEM's createOptimizedPicture for responsive images
  • Price Formatter - Formats prices as Canadian dollars

JavaScript (product-grid.js) - 115 lines

/**
 * Product Grid block.
 *
 * Authoring: add a link to a product index JSON in the block.
 *   | product-grid                              |
 *   | /products/tools/index.json                |
 *
 * Fetches the index, resolves image URLs, and renders a responsive product card grid.
 */

import { createOptimizedPicture } from '../../scripts/aem.js';
import { createTag } from '../../scripts/shared.js';

/**
 * Fetch and return the data array from a product index JSON.
 * @param {string} url - Absolute URL to the index JSON.
 * @returns {Promise}
 */
async function fetchProductIndex(url) {
  const resp = await fetch(url);
  if (!resp.ok) throw new Error(`product-grid: index fetch failed (${resp.status})`);
  const json = await resp.json();
  return json?.data ?? [];
}

/**
 * Resolve a possibly-relative image path against the index URL.
 * e.g. "./media_abc.jpg" + "/products/tools/index.json" → "/products/tools/media_abc.jpg"
 * @param {string} image
 * @param {string} indexUrl
 * @returns {string}
 */
function resolveImage(image, indexUrl) {
  if (!image) return '';
  try {
    return new URL(image, new URL(indexUrl, window.location.origin)).pathname;
  } catch {
    return image;
  }
}

/**
 * Format a price string as Canadian dollars.
 * @param {string} price
 * @returns {string}
 */
function formatPrice(price) {
  const num = parseFloat(price);
  return Number.isFinite(num) ? `CA$${num.toFixed(2)}` : price;
}

/**
 * Build a single product card 
  • .
 * @param {{ sku: string, url: string, title: string, price: string, image: string }} product
 * @param {string} indexUrl - Used to resolve relative image paths.
 * @returns {HTMLLIElement}
 */
function buildCard(product, indexUrl) {
  const li = createTag('li', { class: 'product-grid-item' });
  const link = createTag('a', { href: product.url, class: 'product-grid-link' });

  // Image
  if (product.image) {
    const src = resolveImage(product.image, indexUrl);
    const picture = createOptimizedPicture(src, product.title || '', false, [
      { width: '400' },
      { media: '(min-width: 900px)', width: '600' },
    ]);
    link.append(createTag('div', { class: 'product-grid-image' }, picture));
  }

  // Body: title + price
  const body = createTag('div', { class: 'product-grid-body' });
  body.append(createTag('p', { class: 'product-grid-title' }, product.title || product.sku));
  if (product.price) {
    body.append(createTag('p', { class: 'product-grid-price' }, formatPrice(product.price)));
  }
  link.append(body);

  li.append(link);
  return li;
}

export default async function decorate(block) {
  // Read the authored index URL — works as a hyperlink or plain text path.
  const anchor = block.querySelector('a[href]');
  const text = block.textContent.trim();
  const indexUrl = anchor
    ? anchor.href // DOM href is always absolute; browser resolves relative links
    : new URL(text, window.location.origin).href;

  if (!indexUrl) return;

  // Clear authored content and show loading state
  block.textContent = '';
  block.setAttribute('aria-busy', 'true');

  try {
    const products = await fetchProductIndex(indexUrl);

    if (!products.length) {
      block.append(createTag('p', { class: 'product-grid-empty' }, 'No products found.'));
      return;
    }

    const ul = createTag('ul', { class: 'product-grid-list' });
    products.forEach((product) => ul.append(buildCard(product, indexUrl)));
    block.append(ul);
  } catch {
    block.append(createTag('p', { class: 'product-grid-empty' }, 'Unable to load products right now.'));
  } finally {
    block.removeAttribute('aria-busy');
  }
}

    Accessibility

    ARIA Attributes

    • aria-busy="true" - Indicates loading state during fetch
    • Removed after content loads or on error

    Semantic HTML

    • <ul> / <li> - Proper list semantics for grid
    • <a> - Card wrapper is a semantic link
    • Image alt text derived from product title

    Keyboard Navigation

    • Tab - Navigate between product cards
    • Enter - Activate focused card link
    • Focus indicators visible on all cards

    Performance Considerations

    Image Optimization

    • Responsive images - Multiple breakpoints (400px, 600px)
    • Lazy loading - Native lazy attribute via createOptimizedPicture
    • WebP format - Automatic WebP delivery when supported
    • Aspect ratio - 16:9 defined in CSS prevents layout shift

    Data Loading

    • Single fetch - One request per block instance
    • Async decoration - Non-blocking decorate function
    • Error handling - Graceful degradation on fetch failure

    CSS Performance

    • GPU acceleration - Transform and opacity for animations
    • Grid layout - Native CSS Grid for responsive columns
    • Scoped selectors - All rules prefixed with .product-grid

    Troubleshooting

    Images Not Loading

    Issue: Product images show broken or missing.

    Solution: Check that image paths are resolved correctly:

    // Verify resolveImage is handling your path format
console.log(resolveImage('./media_abc.jpg', '/products/tools/index.json'));
// Should output: /products/tools/media_abc.jpg

    No Products Displayed

    Issue: Grid shows "No products found" despite valid JSON.

    Solution: Verify JSON structure matches expected format:

    // JSON must have "data" array at top level
{
  "data": [ /* products here */ ]
}

    Fetch Fails with CORS Error

    Issue: Console shows CORS policy error.

    Solution: Ensure index JSON is served from same origin or has proper CORS headers.
