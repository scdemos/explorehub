How to Build a Teaser Block

Create elegant card-style teasers with CSS-only styling, hover effects, and special variants

Block CSS-Only Cards Beginner

Overview

The Teaser block is a CSS-only card component that requires no JavaScript decoration. It uses authored DOM structure directly and applies sophisticated styling including borders, hover effects, and theme-aware colors. A special login-teaser-image variant creates an overlapping card on an image backdrop.

Key Features:
  • CSS-Only: No JavaScript required - empty decorate function
  • Card Styling: Heritage-themed borders, padding, and typography
  • Hover Effects: Smooth lift animation with shadow and border color change
  • Theme Support: Light/dark mode with light-dark() CSS
  • Login Variant: Special section-level styling with image backdrop

Implementation

JavaScript (None Required)

Create blocks/teaser/teaser.js:

/**
 * Teaser uses authored DOM structure directly.
 */
export default function decorate() {}

Why no decoration? The teaser's structure is perfect as-is from authoring. All styling is handled via CSS.

How It Works

CSS-Only Architecture

The teaser block demonstrates that not all blocks need JavaScript. The empty decorate() function signals that the authored structure is used as-is, with all presentation handled via CSS.

Hover Animation

main .teaser {
  transition: transform 0.5s var(--ease-out-expo),
    box-shadow 0.5s ease,
    border-color 0.4s ease;
}

main .teaser:hover {
  transform: translateY(-4px);
  box-shadow: var(--shadow-lift-m);
  border-color: light-dark(var(--color-gold), rgb(197 160 89 / 40%));
}

Effect: Card lifts 4px upward, shadow deepens, border turns gold - creating an inviting interactive feel.

Login Teaser Variant

The login variant uses section-level styling (not block-level) to create a special layout:

  1. Image backdrop: .default-content-wrapper image positioned absolutely
  2. Teaser overlay: .teaser-wrapper positioned relatively with higher z-index
  3. Centered card: Teaser appears to float over the image

4. Click Tracking

Add minimal JavaScript for analytics:

export default function decorate(block) {
  block.addEventListener('click', (e) => {
    const link = e.target.closest('a');
    if (link) {
      // Track teaser click
      if (window.adobeDataLayer) {
        window.adobeDataLayer.push({
          event: 'teaser-click',
          teaser: {
            text: block.textContent.trim().substring(0, 50),
            link: link.href,
          },
        });
      }
    }
  });
}

Best Practices

Content

  • Concise: Keep teaser text brief - 1-2 sentences max
  • Action-oriented: Include clear CTA link
  • Hierarchy: Use heading + paragraph structure
  • Icon usage: Optional icon should reinforce message

Design

  • Contrast: Ensure text is readable in both themes
  • Spacing: Don't overcrowd - let content breathe
  • Consistency: Use same teaser style across site
  • Hover feedback: Ensure hover state is obvious

Accessibility

  • Link text: Make links descriptive ("Learn More" better than "Click Here")
  • Color contrast: Test with accessibility tools
  • Focus states: Ensure keyboard users can see focus
  • Motion: Respect prefers-reduced-motion
