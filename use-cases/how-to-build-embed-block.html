How to Build an Embed Block

Embed videos and social content with platform detection, lazy loading, and custom placeholders

Block Media Lazy Loading Intermediate

Overview

The Embed block enables authors to embed third-party content like YouTube videos, Vimeo videos, Twitter posts, and generic iframes. It features platform-specific handling, lazy loading with IntersectionObserver, optional placeholder images with play buttons, and fixed-height variants for precise sizing.

Key Features:
  • Platform Detection: Automatic handling for YouTube, Vimeo, Twitter
  • Lazy Loading: IntersectionObserver delays loading until scrolled into view
  • Placeholder Images: Optional poster image with play button (click-to-load)
  • Fixed Height Variants: Control iframe height with embed (h-400) syntax
  • Responsive: 16:9 aspect ratio by default, custom heights when specified
  • Autoplay Support: Videos can autoplay when loaded via placeholder click

const getFixedHeight = (block) => {
  const fixedHeightClass = [...block.classList]
    .find((className) => /^(?:fixedheight-|fixed-height-|h-)?\d+(?:px)?$/i.test(className));
  if (!fixedHeightClass) return null;

  const match = fixedHeightClass.match(/(\d+)/);
  const value = match ? Number(match[1]) : NaN;
  return Number.isFinite(value) && value > 0 ? value : null;
};

const loadEmbed = (block, link, autoplay, fixedHeight) => {
  if (block.classList.contains('embed-is-loaded')) {
    return;
  }

  const EMBEDS_CONFIG = [
    {
      match: ['youtube', 'youtu.be'],
      embed: embedYoutube,
    },
    {
      match: ['vimeo'],
      embed: embedVimeo,
    },
    {
      match: ['twitter'],
      embed: embedTwitter,
    },
  ];

  const config = EMBEDS_CONFIG.find((e) => e.match.some((match) => link.includes(match)));
  const url = new URL(link);
  if (config) {
    block.innerHTML = config.embed(url, autoplay, fixedHeight);
    block.classList = `block embed embed-${config.match[0]}`;
  } else {
    block.innerHTML = getDefaultEmbed(url, fixedHeight);
    block.classList = 'block embed';
  }
  block.classList.add('embed-is-loaded');
};

export default function decorate(block) {
  const placeholder = block.querySelector('picture');
  const link = block.querySelector('a').href;
  const fixedHeight = getFixedHeight(block);
  block.textContent = '';

  if (placeholder) {
    const wrapper = document.createElement('div');
    wrapper.className = 'embed-placeholder';
    if (fixedHeight) {
      wrapper.style.aspectRatio = 'auto';
      wrapper.style.height = `${fixedHeight}px`;
    }
    wrapper.innerHTML = '
';
    wrapper.prepend(placeholder);
    wrapper.addEventListener('click', () => {
      loadEmbed(block, link, true, fixedHeight);
    });
    block.append(wrapper);
  } else {
    const observer = new IntersectionObserver((entries) => {
      if (entries.some((e) => e.isIntersecting)) {
        observer.disconnect();
        loadEmbed(block, link, false, fixedHeight);
      }
    });
    observer.observe(block);
  }
}

2. Lazy Loading (No Placeholder)

const observer = new IntersectionObserver((entries) => {
  if (entries.some((e) => e.isIntersecting)) {
    observer.disconnect();
    loadEmbed(block, link, false, fixedHeight);
  }
});
observer.observe(block);

Iframe only loads when scrolled into viewport, improving initial page load performance.

3. Click-to-Load (With Placeholder)

  loadEmbed(block, link, true, fixedHeight);
});

User must click to load video, saves bandwidth and gives user control. Autoplay enabled on user action.

Best Practices

Performance

  • Always use placeholders: Dramatically improves initial page load
  • Limit embeds per page: Each iframe is a performance hit
  • Lazy load by default: Don't autoplay without user action
  • Test LCP impact: Embeds above-the-fold can hurt LCP

Privacy

  • Use no-cookie variants: YouTube, Vimeo have privacy-enhanced players
  • Disclose third-party content: Inform users about tracking
  • User consent: Consider requiring consent before loading social embeds

Accessibility

  • Title attribute: Provide descriptive iframe titles
  • Keyboard access: Ensure play button is keyboard accessible
  • Transcripts: Provide text alternatives for video content
  • Captions: Enable YouTube/Vimeo captions by default
